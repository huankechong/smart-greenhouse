# W1 无烙铁接线方案（2026-10-20 实验室未借到焊接工具）

> 背景：ESP32 + 土壤传感器已到货，但**实验室的电烙铁、焊锡丝、万用表都没借到**，传感器排针无法焊。
> 本文档给出**四条不依赖烙铁的路径**，按"今晚就能标定"的优先级排列。
> 传感器实测形态：**只有 3 个空焊孔，没有针**；手头只有裸传感器 + ESP32，杜邦线/面包板可能从同学处借到。

---

## 结论先行

**焊接不是今天的前置条件。** 标定只需要让 AOUT 的模拟电压进到 GPIO34，这一步有多种免焊办法。

| 方案 | 需要什么 | 今天能成吗 | 精度 |
|---|---|---|---|
| **A. 杜邦线公头直插** | 杜邦线（母对公或公对公） | ✅ 只要借到线就能成 | 够用，标定精度无影响 |
| **B. WAGO 221 快接** | 已自购（10/19 到货） | ✅ 若已到 | 略高（接触电阻更小） |
| **C. 单排针 + 免焊压接** | 单排针 1×3P（几毛钱） | ⚠️ 明天到货 | 最好 |
| **D. 等实验室借烙铁** | 借到工具 | ❌ 时间不可控 | — |

**推荐 A 今晚做标定 → C 作为正式方案 → D 有空再补焊。**

关键原理：电容式土壤模块 PCB 上那三个孔，孔径约 1.0–1.2mm；杜邦线**公头的方针是 0.64mm 方形**（对角约 0.9mm），**能直接插进这两个孔**。接触靠孔壁夹紧，标定用的模拟量精度完全够。

---

## 方案 A：杜邦线公头直插（今晚首选）

### 需要的线

要**「公对母」杜邦线**（一端公头、一端母头）。母头直接插 ESP32 排针，公头插传感器焊孔。

> 如果借到的只有「母对母」：剪断一端，把内部**金属插针（0.64mm 方针）**从塑料壳里拉出来半截，露出约 5mm 针杆，剥线压回。母对母线里的插针和公头针杆是同一规格。

### 步骤

1. **确定三个孔的丝印**。翻过来看 PCB 背面，丝印通常写 `VCC / GND / AOUT`（或 `VCC / GND / AO`）。**这是唯一不能猜的一步** —— 猜错把 3.3V 接到 AOUT 会烧传感器，或者信号接地读数恒 0。
   - 拍照放大看丝印，或看模块正面的元件位置判断（电位器旁边通常是 AOUT）。
   - 实在看不清：**先只插 GND 一个孔**，另外两个等看清再插。
2. **剪三条公对母线**，长度 15–20cm（够从传感器到 ESP32 排针）。
3. **每条线的公头拔掉塑料壳**：
   - 用尖嘴钳夹住针杆根部，**往外拽塑料壳**（不是拽针 —— 拽针会从另一端脱出）。
   - 露出约 **5–6mm** 针杆。露出太长插不进 PCB 的孔，太短捏不住。
4. **插进焊孔**：对丝印，一个孔一根线，**插到底**（PCB 背面能看到针尖顶出来）。
5. **另一端母头插 ESP32 排针**：
   - `VCC` → **3V3**
   - `GND` → 任意 **GND**
   - `AOUT` → **GPIO34**
6. **拍照存档** → 跑 `docs/W1到货点火与标定操作指南_2026-10-20.md` 的步骤 3–4。

### 三个坑

| 坑 | 后果 | 怎么避 |
|---|---|---|
| 丝印看错，把 VCC 和 AOUT 接反 | 传感器可能烧 | 一次只插一根，每插一根拍一张照 |
| 针杆露出太长 | 插不进孔，歪了短路 | 露出 5–6mm |
| **忘了共地** | 读数乱跳或恒 0 | GND 必须接 |
| VCC 接 5V（VIN 脚） | 超出 ADC 量程 | 认准丝印 `3V3`，不是 `5V/VIN` |

## 方案 B：WAGO 221 快接端子（已自购）

10/19 下单的 WAGO 221 如果到了，用它比裸插更稳：

1. 打开杠杆 → 插入剥好的线头（裸线约 6–8mm，不能有绝缘皮）
2. 压回杠杆 → 听到"咔"一声
3. 好处：接触电阻比杜邦线公头小，模拟读数更稳；且**免焊、可反复插拔**

> 缺点：占地方，标定后进 3D 底盘要重新规划走线。所以只建议标定阶段用，正式装配走方案 C。

---

## 方案 C：单排针 + 压接（正式方案，1–3 元）

**这是最终应该采用的做法**，因为后面 DHT11、OLED、继电器、浮球开关都要接，总不能每次靠杜邦线公头怼 PCB。

| 买什么 | 规格 | 价格 |
|---|---|---|
| 单排针 | 2.54mm 间距，**1×3P** 排针 ×3 | 几毛钱 |
| 杜邦线 | 母对母 20cm（已有/借） | — |
| 或者直接买 | **2.54mm 预焊排针的土壤模块** | 5–8 元 |

**最快的一条路**：淘宝搜「电容式土壤湿度传感器 v2.0 **已焊排针**」，同款直接带针版 5–8 元。你现在这块是裸板，备用那块大概率也是裸板 —— 换成带针版，后面所有工序都省了。**这一条我建议直接照做。**

## 方案 D：等实验室借烙铁

申请单 v3 里已经列了电烙铁 + 焊锡丝（借用第 7 项）。等借到后：

1. 烙铁 300–350℃，先给烙铁头上一层薄锡（活化）
2. 排针**插正**（用镊子或面包板固定，防受热翘起/掉进板里）
3. 先焊 GND（最容易、最不重要）→ 再焊 AOUT → 最后焊 VCC
4. 每个焊点停留 **2–3 秒**，焊锡铺开成小锥形即可，**不要堆成球**
5. 焊完用**万用表通断档**量三个孔：孔与对应标签丝印之间应"响"

⚠️ 焊接注意：烙铁不能碰传感器芯片（电解电容 / 电位器怕高温）；离位断电；用毕清理焊渣。
