## 结论先行

**焊接不是今天的前置条件 —— 而且全项目只有土壤传感器这一个器件需要焊。**

已逐项核对《花房接线规划表》线序表：DHT11、OLED、继电器、双色 LED、光敏全部是带排针的模块，走 A 型母对母杜邦线直插；浮球开关是干接点接螺丝端子。**借不借到烙铁，都不阻塞 W1 和 W2。**

标定只需要让 AOUT 的模拟电压进到 GPIO34，这一步有多种免焊办法：

| 方案 | 需要什么 | 今天能成吗 | 精度 |
|---|---|---|---|
| **A. 杜邦线公头直插** | 杜邦线（母对公或公对公） | ✅ 只要借到线就能成 | 够用，标定精度无影响 |
| **B. WAGO 221 快接** | 已自购（10/19 到货） | ✅ 若已到 | 略高（接触电阻更小） |
| **C. 单排针 + 免焊压接** | 单排针 1×3P（几毛钱） | ⚠️ 明天到货 | 最好 |
| **D. 等实验室借烙铁** | 借到工具 | ❌ 时间不可控，**但不阻塞** | — |

**推荐 A 今晚做标定 → C 作为正式方案 → D 什么时候借到什么时候补，不急。**

关键原理：电容式土壤模块 PCB 上那三个孔，孔径约 1.0–1.2mm；杜邦线**公头的方针是 0.64mm 方形**（对角约 0.9mm），**能直接插进这两个孔**。接触靠孔壁夹紧，标定用的模拟量精度完全够。

## 方案 A：杜邦线公头直插（今晚首选）

### 需要的线

要**「公对母」杜邦线**（一端公头、一端母头）。母头直接插 ESP32 排针，公头插传感器焊孔。

> 如果借到的只有「母对母」：剪断一端，把内部**金属插针（0.64mm 方针）**从塑料壳里拉出来半截，露出约 5mm 针杆，剥线压回。母对母线里的插针和公头针杆是同一规格。

### 步骤

1. **丝印已确认（2026-10-20 到货照片）** —— 不用再猜了，三个孔从左到右是：

   | 孔位（背面丝印面，自左向右） | 接到 ESP32 |
   |---|---|
   | **GND** | 任意 GND |
   | **5V** | **3V3** ⚠️ 见下方说明 |
   | **OUT** | **GPIO34** |

   ⚠️ **两个必须注意的点**：

   - **丝印写 `5V`，但要接 `3V3`。** 这模块 v2.0 内置稳压、工作范围 3.3–5.5V；而 ESP32 的 ADC 不容忍 5V。v2.0 在 3.3–5.5V 全范围内输出恒为 0–3.0V，所以**接 3V3 不会让输出变小**，正好落在 ESP32 ADC 满量程内。
   - **正反两面的顺序是相反的。** 照片里元件面（正面）从左到右读是 `OUT / 5V / GND`，背面丝印面是 `GND / 5V / OUT` —— 同一排三个孔，**翻过来看顺序就反**。**以你手上那一面的丝印为准，别照着另一面的顺序插。**

   > 顺带确认：板子尺寸 98 × 23mm、PCB 厚约 1.6mm，与 01b 支架的建模参数（板宽 23、板厚 1.5–1.6）一致，**3D 支架不用改**。

2. **剪三条公对母线**，长度 15–20cm（够从传感器到 ESP32 排针）。
3. **每条线的公头拔掉塑料壳**：
   - 用尖嘴钳夹住针杆根部，**往外拽塑料壳**（不是拽针 —— 拽针会从另一端脱出）。
   - 露出约 **5–6mm** 针杆。露出太长插不进 PCB 的孔，太短捏不住。
4. **插进焊孔**：对丝印，一个孔一根线，**插到底**（PCB 背面能看到针尖顶出来）。
5. **另一端母头插 ESP32 排针**：
   - `5V` → **3V3**
   - `GND` → 任意 **GND**
   - `AOUT` → **GPIO34**
6. **拍照存档** → 跑 `docs/W1到货点火与标定操作指南_2026-10-20.md` 的步骤 3–4。

### 三个坑

| 坑 | 后果 | 怎么避 |
|---|---|---|
| 丝印看错，把 VCC 和 AOUT 接反 | 传感器可能烧 | 一次只插一根，每插一根拍一张照 |
| 针杆露出太长 | 插不进孔，歪了短路 | 露出 5–6mm |
| **忘了共地** | 读数乱跳或恒 0 | GND 必须接 |
| VCC 接 5V（VIN 脚） | 超出 ADC 量程 | 认准丝印 `3V3`，不是 `5V/VIN` |

## 方案 D：等实验室借烙铁

申请单 v3 里已经列了电烙铁 + 焊锡丝（借用第 7 项）。等借到后：

1. 烙铁 300–350℃，先给烙铁头上一层薄锡（活化）
2. 排针**插正**（用镊子或面包板固定，防受热翘起/掉进板里）
3. 先焊 GND（最容易、最不重要）→ 再焊 AOUT → 最后焊 VCC
4. 每个焊点停留 **2–3 秒**，焊锡铺开成小锥形即可，**不要堆成球**
5. 焊完用**万用表通断档**量三个孔：孔与对应标签丝印之间应"响"

⚠️ 焊接注意：烙铁不能碰传感器芯片（电解电容 / 电位器怕高温）；离位断电；用毕清理焊渣。

### 🔧 板子识别三路排查（当前唯一硬卡点，照着查一遍）

**第 1 路：换线（最可能，10 秒）**
- 必须用**能传数据**的 USB 线。手机充电线 / 很多 USB 线只有电源没有数据芯 → 电脑看到"unknown device"或干脆什么都不出现。
- 判别法：拿这根线插手机，能传照片的就是数据线。
- 手头有第二根线就换一根试。

**第 2 路：换口（5 秒）**
- 拔掉插笔记本，插**机箱后面板**的口（直连主板，不走 hub）。
- 别插扩展坞 / USB hub / 带充电口的拓展坞。

**第 3 路：查设备管理器（30 秒，判定性最强）**
1. 插着板子，按 `Win + X` → 「设备管理器」
2. 展开「端口 (COM 和 LPT)」
3. 看有没有 `USB-SERIAL CH340 (COMx)`

| 看到什么 | 说明 | 怎么办 |
|---|---|---|
| 有 `USB-SERIAL CH340 (COMx)` | 驱动全通，**板子是好的** | 记下 COM 号，往下走 |
| 有 CH340 但**带黄色感叹号** | 驱动冲突 | 右键 →「卸载设备」→ 拔插板子 → Windows 自动重装 |
| 「端口」里**根本没有 CH340**，但「其他设备」里有 `未知设备` | 数据线问题 or 驱动没绑上 | 换线（第 1 路）后再看；仍无 → 装 `CH341SER.EXE` |
| **完全没有任何新设备出现** | 板子或线根本没通电/没进系统 | 换线 + 换口（第 1+2 路）；还不行 → 板子坏了 |

> 💡 **快速判定法**：设备管理器里插拔板子时，看「其他设备」或「端口」下有没有**新条目闪现**。有闪现 = 硬件和线都通，是驱动绑定问题；**完全没反应 = 线或板子的物理问题**。

### ⛔ 在实测标定完成前，`EN_WATER` 必须保持 0

主程序当前 `SOIL_RAW_DRY = 3200` / `SOIL_RAW_WET = 1300` 是**按通用资料估的值，没在本模块上实测**。跳过标定直接开浇水开关有两种失败模式：

| 实际情况 | 未标定的后果 | 严重度 |
|---|---|---|
| 实际湿态 ≈ 1500（估 1300 偏低） | `map(1500,1300,3200,100,0)` ≈ 91% → **永远不判缺水 → 花一直渴着** | 静默失效，很难发现 |
| 实际湿态 ≈ 800 / 干态 ≈ 2800 | 干态算成 21% → **一直判缺水 → 反复浇水** | **危险**：水箱抽空、盆泡烂，且无任何报警 |

第二种尤其麻烦 —— 溢出会触发连浇 6 轮 + 冷却 10 分钟的保护，但保护是"停手"，不是"不浇"，盆照样会被泡坏。

**硬规矩：标定完成、两个常量填成实测值之前，`EN_WATER` 一律保持 0。** 软件上"不浇水"永远比"浇错水"安全 —— 缺水症状一眼看得出来（湿度%一直很低），浇水过量要等叶子烂了才发现。

> 标定完成后 `soil_calibrate.py --write` 会自动回写这两个常量，回填完再考虑开 `EN_WATER=1`。
