## 四、关键技术决策及理由

| 决策 | 理由 |
|---|---|
| **编译期功能开关**（7 个 `#define EN_x 0/1`：DHT / OLED / WATER / WIFI / MQTT / WEB / LEVEL） | 一套代码从 W1 全关用到答辩全开，每周只改开关重烧 |
| **引脚分配**：土壤 GPIO34 / 光敏 GPIO35 / DHT GPIO33 / 继电器 GPIO26 / LED 25+27 / 浮球开关 GPIO32 | 全落 ADC1（32-39），避开 WiFi 与 ADC2 冲突；34/35 只读 |
| **自动浇水状态机**：监视→浇3s→停30s复测→仍干再浇→连浇6轮转冷却10min（0/1/2/4，v1.1 加状态3=远程手动非阻塞） | 防反复触发；非阻塞保证浇水期间 MQTT/Web 照常响应；v1.5 修复了"再浇分支漏自增导致 6 轮上限永不触发"的高危缺口 |
| **凭据外置 config.h** | UID/WiFi 不进主程序，交报告前只需脱敏一个文件 |
| **3D 工具链：Onshape 概念图 → SolidWorks 手工 → 参数化脚本出 STL（现行）** | 零件尺寸会随实物变，参数化改一个数就重出全套（STL/装配/HTML）；SW 手工建模改一次要重画，且首版必改尺寸 |
| **件 5 LED 灯罩取消** | 没有半透明耗材，白色 PLA 不透光，做了等于把状态灯关掉；改裸 5mm LED（底板 φ5.2 孔） |
