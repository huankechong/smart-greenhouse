8.1 继电器 + 8.2 水泵 · 接线图 v3

花房项目 · 2026-11-09（周一）19:00 C311 用 · 按 11/08 实验室实测修正：继电器 JQC-3FF-S-Z，输入端 = DC+ / DC− / IN（全部是螺丝端子），强电侧 = NC / COM / NO，带 High/Low 触发跳线帽

v3 三处变更：① 继电器输入端 VCC/GND 改为丝印 DC+/DC−；② 全部端子要拧螺丝 → 必带小十字螺丝刀，杜邦线继电器侧剥 8mm 裸线头；③ 排障先拨 High/Low 跳帽，再改 RELAY_ACTIVE_HIGH

四色线速查（v3 实测口径）

线走向
红 · 泵正极充电宝 5V → 剪断处 R1 → 继电器 COM；NO → R2 → 泵红线（NC 不接；裸线头直接压进螺丝端子）
黑 · 泵负极剪断处 B1 → 万可 WAGO 221 → B2 → 泵黑线（直通，不过继电器）
白/绿 · 数据都不接——两侧剪开后各自绝缘胶带包好，防碰到红黑短路
杜邦 ×3（控制）GPIO26→IN（橙）、5V/VIN→DC+、GND→DC−——继电器这头剥 8mm 裸线头拧进螺丝端子（不是排针！）；ESP32 那头照常插排针

现场顺序（11/09 周一 19:00 C311）

  1. 带齐：小十字螺丝刀（最关键）+ 量筒 + 充电宝 + 已剪好的 USB 延长线 + 手机 + U 盘。
  2. 插板 → 烧 RelayPumpTest（板上现在是传感器版固件，非主固件！），串口 115200。
  3. 8.1：按图接继电器（螺丝端子拧线）→ 发 on 听咔哒、看模块灯 → off 断开。没咔哒：先拨 High/Low 跳帽换一档再试；仍不行 → RELAY_ACTIVE_HIGH 改 0 重烧。拍照（素材 8.1）。
  4. 8.2：泵浸 1L 桶半桶水，量筒接水 → 发 w 5（首测 5 秒防溢）记 ml；再测 10s / 5s / 3s 填记录表 → 算 ml/s 平均值。拍出水视频（素材 8.2）。
  5. 浮球极性：万用表蜂鸣档，杆尖朝下（没水）/朝上（有水）各测一次 → 定 LEVEL_WET_CLOSED。
  6. 交打印并行：7 件（06c + 五小件 + 水箱盖）3h25m，20:30 前开打、打到完为止（约 22:20）。
  7. 收尾：烧回主固件 v1.6，桌面擦干，器材清点。
