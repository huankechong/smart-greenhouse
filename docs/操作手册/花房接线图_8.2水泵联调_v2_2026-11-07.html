8.2 水泵联调 · 接线图 v2

花房项目 · D0 = 2026-11-07 用 · 按 11/06 借到继电器实拍修正（JQC-3F(S-Z) 5VDC，High/Low level trigger）

v2 唯一改动：继电器 VCC(+) 接 ESP32 的 5V/VIN（线圈 5VDC，接 3V3 吸不动）；其余与 v1 相同

四色线速查

线走向
红 · 正极充电宝 5V → 剪断处 R1 → 继电器 COM → NO → R2 → 泵红线（整条正极都过继电器）
黑 · 负极剪断处 B1 → 万可 WAGO 221 → B2 → 泵黑线（直通，不过继电器）
白/绿 · 数据都不接——两侧剪开后各自绝缘胶带包好，防碰到红黑短路
杜邦 ×3ESP32 GPIO26→IN、5V/VIN→VCC(+)、GND→GND(-)（实物颜色随意，逻辑对即可）

现场顺序与排障

  1. 按图接完（先不装水），串口 115200 发 on → 应听到"咔哒" + 模块灯亮；发 off 断开。
  2. 串口显示吸合但没咔哒 → RELAY_ACTIVE_HIGH 改 0 重烧（此板出厂多为低电平触发）。
  3. 确认无误后泵浸入 1L 桶半桶水，发 w 5（首测 5 秒防溢，量筒接水）→ 记 ml，重复 10s/5s/3s 填记录表。
  4. 泵电源插充电宝，不插电脑 USB 口（启动电流会触发过流保护）。
  5. 控制侧（IN/GND）与触点侧（COM/NO）光耦隔离——泵回路不需要再接一根 GND 回 ESP32，别多接。
  6. 测完收尾：烧回主固件 v1.6，桌面擦干，借的器材还回。
