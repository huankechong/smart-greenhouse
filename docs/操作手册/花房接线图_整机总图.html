花房项目 Smart GreenHouse · 引脚与固件 GreenHouse_v1.ino 第 55–61 行逐一核对 · ESP32 直插 11/12 实测（跨距正好 a↔i）· 与《docs/操作手册/花房接线规划表.md》§三同口径（冲突以此图 + 固件为准）· 模块针序一律以实物丝印对号入座

五条铁律：① 模拟线只在 GPIO32–39（ADC1）——土壤 34 / 光敏 35；② 全系统共地只有一处——蓝轨单点回 ESP32 GND；③ 红轨/蓝轨与主孔区不互通，电源线别插进主区孔；④ 同位号竖条才连通——a–e 一条 / f–j 一条，跨位号不通、跨中沟不通；⑤ 电源轨中点断成 2×25 两段——跨段必接轨桥（清单#3/#4）

二·补、按元器件的接口对照表（本端接口 → 对端接口 · 核对视角）

三、ESP32 端口占用总表（= 固件 55–61 行 + I2C 默认）

GPIO丝印（直插位）接谁方向为什么是这个脚
34D34（a4）土壤 OUTADC1 只进ADC1 组，WiFi 开启不受影响；只读脚不能接输出设备
35D35（a5）光敏 AOADC1 只进同上；DO 弃用
33D33（a7）DHT11 DATA数字双向单总线，模块自带上拉
32D32（a6）浮球干接点数字输入外接 1kΩ 上拉 + 100nF 滤抖；fail-safe
26D26（a9）继电器 IN数字输出普通 IO，无启动毛刺历史问题（v1.3 已锁）
25 / 27D25 / D27（a8/a10）LED 红 / 绿数字输出模块带限流电阻，直驱
21 / 22D21 / D22（i11/i14）OLED SDA / SCLI2C硬件 I2C 默认脚（0x3C 实扫确认）
VINVIN（a15）继电器 DC+电源 5V线圈 5VDC；USB 供电时 ≈4.7V 可用；绝不用 3V3
3V33V3（i1）红轨母线电源 3.3V喂 4 个传感器 + 浮球上拉
⚠️ 禁用GPIO 6–11 / 12 / 4 / 13 / 14 等——6–11 接 flash 碰了变砖；12 启动脚拉错刷不进固件；4/13/14 属 ADC2 WiFi 一开读数全废——本机均未用

四、通电前 60 秒核对（打勾才上电）

  1. ESP32 插稳：左排 a1–a15 / 右排 i1–i15 全针入孔，板身不翘；USB 朝 1 位端
  2. 轨桥已接：红 25↔26、蓝 25↔26 两根桥在（缺桥则第 2 段轨全部无电）
  3. 共地单点：ESP32 GND → 蓝轨只有 #2 一根线（#28 继电器 DC− 借蓝轨）
  4. 模拟双线：土壤 OUT→D34、光敏 AO→D35，没插到 ADC2 组
  5. 继电器供电：DC+ 接的是 VIN 不是 3V3；线圈 5VDC
  6. 触点侧：接 COM+NO，NC 空着（接 NC = 一上电就抽水）
  7. 浮球 RC：节点全在位 18 同一条竖条（a=R1 / b=浮球1 / c=C1 / e=D32）
  8. 二极管：断电态红笔泵−黑笔泵+ 读 0.5–0.7V；读 0/双向通 = 击穿，立刻拆
  9. 跳帽：High/Low 跳帽在 H 档；吸合逻辑反了先拨 L 档验证，再查 RELAY_ACTIVE_HIGH
  10. 固件先决：联调烧 RelayPumpTest，测完烧回 GreenHouse_v1 v1.6
