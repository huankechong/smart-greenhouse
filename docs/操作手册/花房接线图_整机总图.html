三、ESP32 端口占用总表（= 固件 55–61 行 + I2C 默认）

GPIO丝印接谁方向为什么是这个脚
34D34（左列4）土壤 OUTADC1 只进ADC1 组，WiFi 开启不受影响；只读脚不能接输出设备
35D35（左列5）光敏 AOADC1 只进同上；DO 弃用
33D33（左列7）DHT11 DATA数字双向单总线，模块自带上拉
32D32（左列6）浮球干接点数字输入外接 1kΩ 上拉 + 100nF 滤抖；fail-safe
26D26（左列9）继电器 IN数字输出普通 IO，无启动毛刺历史问题（v1.3 已锁）
25 / 27D25 / D27（左列8/10）LED 红 / 绿数字输出模块带限流电阻，直驱
21 / 22D21 / D22（右列11/14）OLED SDA / SCLI2C硬件 I2C 默认脚（0x3C 实扫确认）
VINVIN（左列15）继电器 DC+电源 5V线圈 5VDC；USB 供电时 ≈4.7V 可用；绝不用 3V3
3V33V3（右列1）红轨母线电源 3.3V喂 4 个传感器 + 浮球上拉
⚠️ 禁用GPIO 6–11 / 12 / 4 / 13 / 14 等——6–11 接 flash 碰了变砖；12 启动脚拉错刷不进固件；4/13/14 属 ADC2 WiFi 一开读数全废——本机均未用

四、通电前 60 秒核对（打勾才上电）

  1. 共地单点：ESP32 GND → 蓝轨只有 #2 一根线（#28 继电器 DC− 借右板蓝轨）
  2. 模拟双线：土壤 OUT→D34、光敏 AO→D35，没插到 ADC2 组
  3. 继电器供电：DC+ 接的是 VIN 不是 3V3；线圈 5VDC
  4. 触点侧：接 COM+NO，NC 空着（接 NC = 一上电就抽水）
  5. 浮球 RC：节点全在行 21 的 a–e 列（a=R1 / b=浮球1 / c=C1 / e=D32），不跨中沟
  6. 二极管：断电态红笔泵−黑笔泵+ 读 0.5–0.7V；读 0/双向通 = 击穿，立刻拆
  7. 跳帽：High/Low 跳帽在 H 档；吸合逻辑反了先拨 L 档验证，再查 RELAY_ACTIVE_HIGH
  8. 固件先决：联调烧 RelayPumpTest，测完烧回 GreenHouse_v1 v1.6
