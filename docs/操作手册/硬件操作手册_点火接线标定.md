### 板型与丝印（2026-10-20 实拍核对，30 脚 ESP-32-DevKitC）

实物是 **30 脚板**（不是 38 脚）。丝印读法（**背面视角，USB 口朝下**）：

| 排 | 丝印（从上往下） |
|---|---|
| **左排** | EN · VP · VN · **D34** · D35 · D32 · D33 · D25 · D26 · D27 · D14 · D12 · D13 · GND · VIN |
| **右排** | D23 · D22 · TX0 · RX0 · D21 · D19 · D18 · D5 · D17 · D16 · D4 · D2 · D15 · GND · **3V3** |

| 要接的 | 在板子哪 | 提醒 |
|---|---|---|
| **3V3** | 右排**最下面** | 传感器 `5V` 脚接这里（丝印写 5V，但接 3V3！） |
| **GND** | 右排倒数第二 / 左排倒数第二 | 任选 |
| **GPIO34** | 左排**从上数第 4 个**（丝印 `D34`，`VN` 下面） | 传感器 `OUT` 接这里；别数到 D35（那是光敏的位置） |

## 一、接线表（土壤传感器，三根线）

> 传感器丝印是 **`GND` / `5V` / `OUT`**（不是 VCC/GND/AOUT），**正反两面顺序相反**——以手上那一面的丝印为准。

| 传感器针脚 | → | ESP32 | 必看 |
|---|---|---|---|
| **5V**（丝印） | → | **3V3** | 模块 v2.0 内置稳压（3.3–5.5V 均可），且输出恒为 0–3.0V——接 3V3 正好占满 ADC 量程；接 5V 反而可能超 ADC 上限 |
| **GND** | → | GND | 任一 GND；**必须共地** |
| **OUT** | → | **GPIO34** | ADC1 只读脚；GPIO34 = 左排第 4 个 |

**三个必踩的坑**（三份原文共识）：① 别接 GPIO35（光敏的位置，插了读数乱跳干扰判断）；② 一定要共地（只接 5V 和 OUT 会乱跳）；③ 丝印 5V 接 3V3（不是笔误，见上表）。

## 二、接线方式 A（现行定案）：焊接排针

**前提**：买传感器随附 1×3P 排针（✅ 已到）；只缺烙铁（实验室借，D0 现场核对）。

### 2.1 借用清单（三样）

| # | 借什么 | 规格 | 备注 |
|---|---|---|---|
| 1 | 电烙铁 | 60W 以内，尖嘴头 | 烙铁架、海绵一起借最好 |
| 2 | 焊锡丝 | 0.8–1.0mm 含助焊剂 | 0.8mm 更好控温 |
| 3 | 万用表 | 通断档 + 直流 0–20V | 焊完验证通断 |

### 2.2 焊接步骤（10 分钟）

1. **摆件**：PCB 元件面朝上，排针插三个焊孔，手指按住。
2. **活化烙铁**：300–350℃，烙铁头挂一层薄锡（不活化锡不沾头）。
3. **固定排针**：**面包板当治具**——排针三针插面包板中间行，PCB 架在排针上对准焊孔（没有面包板用镊子夹，原则是排针垂直不动）。
4. **焊接顺序 GND → OUT → 5V**：GND 最容易焊先拿下；5V 最后（万一失手传感器不因误接损坏）。每点手法：烙铁头带一点锡 → 斜碰**焊盘和排针根部**（不是针尖）→ 停 2–3 秒喂锡丝 → 锡铺开成**小锥形**即撤 → **不堆球**（球状易虚焊）。
5. **冷却检查**：自然冷却（别吹，会裂纹）；焊点应光亮小锥形。
6. **万用表验证**：通断档，表笔固定 GND 针，依次碰 OUT、5V → **都响**；再量 OUT↔5V → **不响**（响=短路，返工）。
7. **接线**：焊好后用**母对母**杜邦线（套件第 9 项公对母的母头半边）按 §一接线表接三根。

## 三、接线方式 B（备选）：免焊公头直插（烙铁借不到时）

> 原理：传感器焊孔径 1.0–1.2mm，杜邦线公头方针 0.64mm（对角约 0.9mm），**能直接插进孔靠孔壁夹紧**，标定精度够用。零工具零成本。

1. 剪三条**公对母**线（15–20cm）。
2. 公头**拔掉塑料壳**：尖嘴钳夹针杆根部，拽壳不拽针，露出 5–6mm 针杆。
3. 对丝印一个孔一根线，**插到底**（PCB 背面能看到针尖）。
4. 母头端按 §一接线表接 ESP32。
5. 只有母对母线时：剪断一端，把内部金属插针拉出半截剥线压回，即自制公头。

**免焊专属坑**：针杆露出太长插不进/歪了短路（露出 5–6mm 为宜）；一次只插一根、每插一根拍一张照（防接反烧模块）。

> 备选还有 **WAGO 221 快接**（已到货 4 只：剥线 11mm → 掀杆插线 → 压回听"咔"）：接触电阻比杜邦小、可反复插拔，但占地方，只建议标定阶段临时用。
> ~~「买已焊排针模块 5–8 元」~~ **作废**——排针已随传感器赠送，此路不再需要。

## 步骤 1.5：接线自检（30 秒，接完线必做）

```bash
cd "D:/Documents/workbuddydocument/2026-10-17-08-59-13"
"C:/Users/junbo/.workbuddy/binaries/python/envs/default/Scripts/python.exe" \
  "outputs/代码/花房代码/tools/soil_watch.py" --port COM6
```

| 读数表现 | 含义 | 怎么办 |
|---|---|---|
| raw ≈ 0–200 纹丝不动 | ❌ OUT 没接上/没供电/没共地 | 查 5V→3V3、GND→GND；确认 OUT 在 D34 |
| raw > 4000 纹丝不动 | ❌ OUT 悬空或短路 | 查 5V 是否漏接/接反 |
| raw 几百～三千多且会动 | ✅ 接线通了 | 进步骤 2 |
| 手指捏探针读数上跳 | ✅ 更稳（人体接地） | — |

> 未接传感器时 raw 稳定 95–105（≈0.08V）是 GPIO34 悬空特征值——接上后**必须明显变化**才算通。

4. **自动回写**：数据通过自检（干湿差 ≥800、方向正确）时脚本直接改主程序 `SOIL_RAW_DRY` / `SOIL_RAW_WET`；不通过会**拒写**并给排查提示——那是接线/焊接问题，**不要手动硬填常量**。

### ⛔ 硬规矩（标定前必读）

主程序当前 `SOIL_RAW_DRY=3200` / `SOIL_RAW_WET=1300` 是**通用资料估值，未在本模块实测**：

| 估偏方向 | 后果 |
|---|---|
| 估高 | 湿态算成 ~91% → 永远不判缺水 → **花一直渴着**（静默失效） |
| 估低 | 干态算成 ~21% → 一直判缺水 → 反复浇水，**水箱空、盆泡烂**（危险） |

**标定完成、实测值回填之前，`EN_WATER` 一律保持 0。**（v1.6 已加标定非法 setup 硬停机兜底，见固件 README。）

## 常见问题速查（合并去重版）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `board list` 空 | 数据线只供电 | 换线（最常见） |
| `board list` 有端口但 Unknown | 驱动没装好 | 设备管理器卸载 CH340 → 拔插 → 重装 CH341SER |
| 串口没输出/乱码/每秒重连 | 波特率不是 115200 | 改 115200 |
| `not responding / not in sync` | 没进下载模式 | 按住 BOOT，`Connecting....` 后松开 |
| raw 恒为 0 | OUT 没接到 GPIO34 / 没共地 | 重查接线，量 OUT 对 GND 电压 |
| raw 恒为 4095 | OUT 悬空 / 5V 没接 / 接了 5V(VIN) | 认准丝印 3V3 |
| 干湿差 < 800 | 探针没全湿 / 模块坏 / 焊接虚焊 | 换水重测；万用表量焊点；仍不行换传感器 |
| 湿度一直 0% | 干湿填反 | 脚本会拦；真发生改两常量顺序 |
| 万用表量 OUT↔5V 响了 | 焊接短路 | 返工重焊该点 |
