## 二、三条红线（接错最先出事的就这三个）

1. **模拟线必须在 GPIO32–39（ADC1 组）**：土壤 34 / 光敏 35。ESP32 的 ADC2 组在 WiFi 开启后直接失效——这是和课上 UNO 最大的差异，也是最高频翻车点。（GPIO32 原规划给雨滴模块，现已取消，空出备用。）
2. **GPIO34 / 35 是"只进不出"引脚**：没有内部上拉、不能输出，只能接传感器输出；绝不能接 LED 或继电器。
3. **必须共地**：所有模块 GND 汇到面包板 GND 轨，再单点接到 ESP32 GND。共地断了会出各种灵异读数。

## 三、面包板布局建议

- **30Pin ESP32 跨不进标准面包板中沟**（板比沟宽）：把两块面包板**并排拼成大板**，ESP32 骑在两板交界，左右引脚各进各板。套件正好是 2 块。
- 电源轨：红线轨走 3V3、蓝线轨走 GND，各从 ESP32 引一次；VIN 5V 只喂继电器一个。
- 分区建议：
  - **左区（模拟）**：土壤 / 光敏 / 温湿度，靠近 GPIO32–35 一侧；
  - **右区（数字/输出）**：OLED / 双色 LED / 继电器，靠近 GPIO21/22/25/26/27 一侧；
  - **水泵线走板外**，单独用 **22AWG 端子线**拉到继电器螺丝端子（**不要用杜邦线**，见三·补），别在面包板上绕。

## 三·补、每根线用什么线材（2026-10-19 补）

前面只说"A 接到 B"，没说"用哪种线"。这一节补上，接线当天照着剪/拿就行。

### 四种线，别混用

| 代号 | 线材 | 用在哪 | 数量 |
| --- | --- | --- | --- |
| **A** | 套件 40P **杜邦线**（母对母，约 20cm，线序彩色） | 模块针脚 → ESP32 排针（两端都是母头） | 18 根 |
| **B** | **面包板硬芯跳线**（0.5mm 实心，套件配的那种） | 同一块面包板上的短距离：电源轨分区、模块就近借电 | 6–8 根 |
| **C** | **22AWG 硅胶线 / 端子线**（能过 1A，软、耐折） | **只给水泵回路**用，杜邦线不许走水泵电流 | 3 根 × 30cm |
| **D** | φ4×φ8 **硅胶软管**（这是水路，不是电线，别混） | 水泵出水嘴 → 盆内水管夹 | 约 1.2m |

> 40P 杜邦线是"母对母"。若 ESP32 直接骑在面包板上（推荐，见第三节），模块到板子用 A；若 ESP32 用排针立在板边，则用**公对母**那一半（套件 40P 通常公母各半，先翻一遍再剪）。

### 每种元件的具体线序

| 元件 | 针脚 → 接到 | 线 | 建议色 |
| --- | --- | --- | --- |
| **土壤湿度** | VCC → 3V3 红轨 / GND → 蓝轨 / AOUT → GPIO34 | A × 3（**用 30cm**，盆离板远） | 红 / 黑 / 黄 |
| **DHT11** | VCC → 3V3 红轨 / GND → 蓝轨 / DATA → GPIO33 | A × 3（20cm） | 红 / 黑 / 白 |
| **OLED** | VCC → 3V3 / GND → GND / SCL → GPIO22 / SDA → GPIO21 | A × 4（20cm） | 红 / 黑 / 绿 / 白 |
| **继电器** | VCC → **VIN 5V**（不是 3V3）/ GND → 蓝轨 / IN → GPIO26 | A × 3（20cm） | 红 / 黑 / 蓝 |
| **双色 LED** | GND → 蓝轨 / R → GPIO25 / G → GPIO27 | A × 3（20cm） | 黑 / 红 / 绿 |
| **光敏**（可选） | VCC → 3V3 / GND → 蓝轨 / AO → GPIO35 | A × 3（20cm） | 红 / 黑 / 紫 |
| **雨滴**（已取消） | ~~VCC → 3V3 / GND → 蓝轨 / AO → GPIO32~~ | — | 不再借用，此行留档 |
| **电源轨** | ESP32 3V3 → 红轨（1 根）；ESP32 GND → 蓝轨（1 根，**单点**） | B | 红 / 黑 |
| **水泵回路** | 5V 电源正 → COM；NO → 泵正；泵负 → 5V 电源负 | **C × 3**（30cm） | 红 / 红 / 黑 |

合计：**杜邦线 18 根**（不含两个可选模块）+ 硬芯跳线 6–8 根 + 水泵端子线 3 根。

### 三个容易踩的点

1. **水泵不许用杜邦线**。3W 泵约 600mA，杜邦线的压接端接触电阻大，长时间通流会发热、压降会让泵转速掉一半。第三节那句"水泵线用杜邦线"本次已改成 22AWG 端子线。
2. **双色 LED 到底是什么形态，到货才能定**：
   - 若是**模块**（3 针 GND/R/G）→ 板上自带限流电阻，按上表直连即可；
   - 若是**裸 5mm 灯珠**（4 针脚或 2 长脚 + 2 短脚）→ **必须串 220Ω 限流电阻**（3.3V 下约 6mA），直连会超过 GPIO 40mA 上限，烧灯或烧脚。这一项文档之前没写，属缺口。
3. **共地只有一处**。所有模块 GND 先汇到蓝轨，蓝轨用**一根**线回 ESP32 GND。多点接 GND 会形成地环路，模拟读数会抖。

## 三·补二、水泵实物规格（2026-10-19 实测）

| 项 | 值 |
|---|---|
| 型号 | 3W USB 底吸泵（USB 供电，无开关） |
| 泵体 | **41 × 39 × 30 mm**（含出水嘴高 37） |
| 底脚（吸盘） | 32 × 28 mm |
| 功率 / 流量 / 扬程 | 3W · 130 L/h · 50 cm |

> ⚠️ **它没有开关**：只要供电就一直转。所以"插上电一直转"通常是**正常现象**——说明它现在直接吃着电，
> 没经过继电器断开。要么是直插了 USB 电源，要么继电器接在 **NC（常闭）**，要么继电器模块是低电平触发
> 而代码当成高电平用。三种情况的判别见第六节故障速查。

## 四、水泵怎么供电（免焊）

一句话原则：**泵吃独立 5V，继电器只当开关，ESP32 只出信号。** 泵电流一点不经过 ESP32 板。

### 三种供电方案

| 方案 | 怎么接 | 优点 | 代价 | 推荐度 |
| --- | --- | --- | --- | --- |
| **A 独立 5V/2A 充电头**（+ ESP32 另用电脑 USB） | 泵 → 继电器 → 充电头 | 泵启动冲击完全不干扰 ESP32，模拟读数最稳 | 要占两个插座 | **★★★ 答辩现场首选** |
| **B 一个 5V/3A 头 + USB 分线** | 一路给 ESP32 USB，一路经免焊端子给继电器 COM | 一个插头搞定，天然共地 | 分线器质量差会掉压，泵启动瞬间可能把 ESP32 拉到重启 | ★★ |
| **C 充电宝** | 同 A 或 B | 无线、便携 | **充电宝低电流会自动断电**（ESP32 待机才 100mA 级、泵又是间歇工作），演示到一半黑屏 | ★ 不推荐 |

### 电流账（选电源的依据）

| 项 | 数值 |
| --- | --- |
| 泵稳态 | **600mA**（3W ÷ 5V） |
| 泵启动瞬间 | **1.2–1.8A**（直流电机启动 2–3 倍，持续 <100ms） |
| ESP32 WiFi 发射峰值 | ~250mA |
| **电源下限** | **≥2A**（方案 A）；**≥3A**（方案 B，两个负载共用一个头） |

### 接法

```
5V 电源 +  ──────► 继电器 COM
                    继电器 NO ──────► 泵 红线 (+)
泵 黑线 (−) ──────► 5V 电源 −

继电器 VCC 仍由 ESP32 的 VIN(5V) 供，IN → GPIO26
线圈侧与触点侧天然隔离，所以泵电源不需要和 ESP32 共地
```

- **必须接 COM + NO（常开）**：断电、复位、程序跑飞时泵自动停。接成 NC 就变成"一上电就抽水"，蓄水瓶抽干都停不下来。
### USB 款泵的电源到底插哪儿（2026-10-19 补）

**结论：插独立的 5V 充电头，中间串继电器；绝对不要插 ESP32 板上那个 USB 口。**

```
       USB 充电头 5V/2A
              │  USB 线
        ┌─────┴─────┐
        │  USB 延长线 │（A 公 → A 母，剪断中间）
        └─────┬─────┘
     红线 +5V ─┤─ [保险 1A] ─ COM ─(继电器)─ NO ─┐
               └─ 红：接泵的 +5V（原装 USB 头插回母座）
     黑线 GND ─────────────────────────────────┴─ 泵 GND
```

**三种接法，按手头材料选一种**：

| 方案 | 怎么做 | 代价 | 推荐 |
|---|---|---|---|
| **A. 剪一根 USB 延长线**（推荐） | A 公-A 母线剪断，红线断口串 `保险 → COM/NO`，黑线直通；泵原装 USB 头插进延长线的母座 | 一根 5 元延长线，**不动泵** | ★★★ |
| B. USB 免焊端子（母座转螺丝） | 充电头插母座，端子螺丝引出红/黑 → 保险 → COM/NO | 5 元，线材稍乱 | ★★ |
| C. 直接剪泵的线 | 剪断泵线接到继电器 | 泵报废风险、无保修 | ✗ 不建议 |

**为什么不能插 ESP32 的 USB 口**：

1. 那个口是给板子供电/烧录的，泵启动瞬间 1.2–1.8A 会把它拉垮，轻则板子重启、重则烧 USB 保护器件；
2. 插上去就等于**绕过继电器**——泵会一直转，正是你现在看到的现象；
3. 电脑 USB 口只保证 500mA，泵一启动就触发限流断电。

**如果只有一个插座**：用 5V/3A 充电头 + USB 分线器，一路给 ESP32、一路给泵；**泵那一路仍然要串继电器**，两路共地（同一个头出来天然共地）。

> 续流二极管 1N4007 仍然要并联在**泵的两根线**上（不是 USB 线的红黑，是泵本体出线或母座后的红黑），阴极朝 +5V。

### 两个加固（要做，别跳）

1. **续流二极管 1N4007**：反并联在泵两端——**阴极（有色环那端）接 +5V，阳极接泵 −**。直流电机是感性负载，断电瞬间的反电动势会打火花烧继电器触点（触点寿命从十万次掉到几千次），也会窜进模拟通道让土壤读数乱跳。一块钱的事。
2. **1A 自恢复保险**（如 MF-R110）串在 COM 前：泵堵转（水管打折、盆土太实）时电流会冲到 2A 以上，不至于把电源或线烧了。

### 加固怎么做（免焊，10 分钟）

**材料**：1N4007 ×1（买 5 只备用，一只 1 毛）、MF-R110 ×1（备 1）、小十字螺丝刀、剥线钳。

**接线位置**（在上一节那张图的基础上多两个元件）：

```
5V 电源 + ──► [保险 MF-R110] ──► 继电器 COM
                                  继电器 NO ──► 泵 红线 (+)
泵 黑线 (−) ──► 5V 电源 −

                  ┌──── 1N4007（色环端朝上）────┐
泵 (+) ───────────┤                            ├─────────── 泵 (−)
                  └──── 阳极（无色环，朝下）──────┘
       即：二极管与泵并联，阴极接 +，阳极接 −
```

**四步做完**：

1. **断电**，泵从电源上完全断开（不是只关继电器，要把 5V 拔掉）。
2. **二极管整形**：两根引脚各向外弯 90°，跨距调到正好够到泵的两个接线端（约 15–20mm）。
3. **压接**：
   - 泵若是**免焊端子**（螺丝压线那种）→ 把二极管引脚和泵线**一起压进同一个端子**，拧紧；
   - 泵若是**裸线**→ 用一小段接线端子排（2 位，2 元）中转，二极管并在这两位上。
4. **通电前必须验极性**（这一步不能省，装反等于**把电源直接短路**）：

   | 万用表档位 | 红表笔 | 黑表笔 | 正常读数 |
   | --- | --- | --- | --- |
   | 二极管档（→\|—） | **泵 −** | **泵 +** | **0.5–0.7 V**（正向导通） |
   | 同上，反过来 | 泵 + | 泵 − | **OL / 显示 1**（不导通） |

   第一行读 0.5–0.7V 才算装对。**如果两行都通（都读到接近 0）→ 说明二极管已经击穿或装错，立刻拆掉**，否则上电瞬间 5V 电源被二极管短路，轻则电源保护重启、重则烧线冒烟。

**为什么反着接**：正常工作时二极管反向截止，等于不存在；泵断电那一瞬间电机线圈产生反向电压，二极管正向导通把它泄放掉，把火花消灭在线圈内部，不让它跑到继电器触点和模拟通道上去。

> 保险的位置也有讲究：串在 **COM 之前**（电源侧），这样保险坏了自己断，泵和线都保住了；串在 NO 之后只保护泵、不保护线。

### 首次通电（空载，别先接水管）

1. 泵不进水、水管不接花盆，只通电听继电器
2. **有"咔嗒" + 泵转** → 继电器和信号都对，可以接水路
3. **有"咔嗒"但泵不转** → 查泵回路：COM/NO 接反了？5V 电源没输出？线没压紧？
4. **没有"咔嗒"** → 查 GPIO26 信号和触发极性（`config.h` 里的 `RELAY_ACTIVE_HIGH`，模块是低电平触发就改成 0）

- [ ] **保险串在 COM 之前**（电源侧），不是串在 NO 之后

## 六、常见故障速查（排查过程 = 报告"失败与排查"素材）

| 现象 | 先查什么 |
| --- | --- |
| 模拟读数一直是 0 或 4095 | 线是不是误插了 ADC2 组引脚（GPIO4/12/13/14 等）；共地断没断 |
| WiFi 一开模拟读数全乱 | 模拟线在 ADC2 脚上，换回 32–39 |
| OLED 不亮 | 跑一遍 I2C 扫描看地址（通常 0x3C）；SCL/SDA 是否插反 |
| 继电器不吸合 / 动作相反 | 触发极性（高电平/低电平触发），代码取反即可 |
| 双色 LED 颜色反了 | R/G 对调，改代码或换线，不算故障 |
| DHT11 读出 nan | 等模块上电稳定 2 秒再读；DATA 线插稳 |
| 水泵不转 | 先听继电器咔嗒声：有咔嗒=查水泵回路；无咔嗒=查 GPIO26 信号与触发极性 |
| **水泵一通电就一直转** | ① 泵是不是直接插了 USB 电源（绕过继电器）；② 触点是不是接在 **NC**（应接 COM+NO）；③ 继电器模块是**低电平触发**却把 `RELAY_ACTIVE_HIGH` 设成 1 → 代码写 LOW 反而吸合，改成 0 |
| 上电瞬间泵"咔"一下才停 | 继电器上电毛刺，固件 v1.3 已改为"先锁断电平再开输出"；仍出现则模块本身无上拉，见下 |
| **泵一停/一启动，土壤或光敏读数就跳一下** | **没装续流二极管，或装反了**（见第四节加固）；其次查泵电源与信号线是否并排走太近 |
| 泵转但继电器触点很快发黑/粘连 | 同上——感性负载打火，必须加 1N4007 |
| 一上电泵就转、程序管不住 | 触点接到了 **NC**（常闭），改接 COM+NO |
