## 一、4 天核心技能路线（每天 30–60 分钟）

> SolidWorks 自带官方教程：菜单 **帮助 → SOLIDWORKS 指导教程**（中文，跟完前 3 课 ≈ 覆盖 Day 1 全部内容），配合下表练习效果最好。

### Day 1｜草图 + 拉伸凸台：传感器支架（60 分钟）

**学**：草图（矩形/圆/智能尺寸/完全定义）→ 拉伸凸台/基体 → 圆角  
**练**：土壤传感器 L 型支架（托住传感器板 + 两个 M3 螺丝孔）

| 步骤 | 操作                   | 要点                                       |
| -- | -------------------- | ---------------------------------------- |
| 1  | 新建 → 零件              | 界面：前视/上视/右视三个基准面                         |
| 2  | 前视基准面 → 草图 → 画 L 形轮廓 | L 臂长按传感器板实测（到货后量）                        |
| 3  | 智能尺寸（S 快捷键）标注        | 每条边被尺寸/几何关系锁死，状态栏显示"完全定义"才算合格（不能有蓝色欠定义线） |
| 4  | 特征 → 拉伸凸台，厚度 3mm     | 打印件壁厚 ≥2mm                               |
| 5  | 特征 → 圆角 R2           | 去锐边，打印更稳                                 |

**验收**：草图完全定义 + 零件另存为 STL（文件 → 另存为 → 类型选 .stl → 选项 → 分辨率选"精细"）

### Day 2｜旋转 + 圆周阵列 + 抽壳：蓄水瓶盖（60 分钟）

**学**：旋转凸台（Revolve）→ 圆周阵列 → 抽壳  
**练**：水泵出水口对接盖（圆盘 + 中心孔 + 环形加强筋）

- 旋转 = 画一半截面 + 中心线，绕轴转一圈 → 圆形件标准做法
- 抽壳 2mm 做盆/盖类
- 阵列 4 根辐条练 Circular Pattern（特征阵列）

**验收**：一个带中心孔的圆盖 STL

### Day 3｜参考基准面 + 异型孔向导：双色 LED 灯座（45 分钟）

**学**：新建参考基准面 → 异型孔向导（Hole Wizard）→ 打印件孔不用攻螺纹（自攻）  
**练**：LED 灯座（圆柱凹槽嵌 5mm LED + 两孔走线）

**验收**：灯座 STL + 能说清"为什么要建参考平面而不是直接在面上画"

### Day 4｜装配体 + 打印前检查（45 分钟）

**学**：装配体（Assembly）基础 → 插入零件 + 同心/重合配合 → 干涉检查（评估 → Interference Detection）→ STL 打印性自查

| 打印自查项 | 标准                     |
| ----- | ---------------------- |
| 壁厚    | ≥2mm                   |
| 悬垂    | <45° 或加支撑              |
| 孔径    | M3 过孔打 3.2mm（FDM 热胀缩孔） |
| 底面    | 平整、面积够大（首层粘床）          |
| 尺寸    | 对照实物再核一遍               |

**验收**：支架+瓶盖+灯座插入装配体 → 干涉检查零干涉 → 3 份 STL 拷 U 盘

### 容器外购清单（10-18 更新，对齐 DeepSeek 整机装配模型尺寸）

模型基准：花盆 = 上口内径 74/外径 82、下底 58、高 85mm 锥形陶盆；水箱 = 118×90×60mm 剖壁敞口盒。

| 物品 | 搜索词 | 规格 | 预算 | 说明 |
|---|---|---|---|---|
| **花盆** | 淘宝"红陶多肉盆 8cm 无孔" | **口径 8 / 外径 9.5 / 高 8cm，无孔** | ¥3–9 | 与模型 1:1（潮州通货规格）；无孔=桌面不渗水；红陶盆沿圆度好，传感器挂钩式支架（挂 R37–41 盆沿）贴合更稳。备选：土立方园艺清仓款 ¥8.9；义乌购元裕 ¥3.25（10 个起批，可拼单） |
| **水箱** | 京东"保鲜盒 长方形 透明 14x9x6" | **14×9×6cm 平盖简款**（不带分隔/卡扣锁） | ¥7–15 | 常见规格 12×8×5 / 12.5×8.5×5.5 / 14×9×6 均可；透明可见水位；平盖好走泵线和水管；搬运盖盖防洒、演示掀盖 |

水箱差几毫米无妨——底座两片式（06a/06b）安装位有 ±3mm 调整余地，真正卡尺寸的整流罩类件设计中没有。原"FDM 层线渗水 + 水箱占机时 20–30h 不打印"的 make-vs-buy 决策不变，写进答辩叙事。

> **下单时点：等 10/21 硬件到货摆完再买**——ESP32/水泵/管路实际占位可能让水箱改选更紧凑的 12×8×5。
