# AR25 · 底盘小件嵌槽（完全嵌平）· 2026-11-08

> 触发：领导要求「根据每个零件的大小在底座开槽，让它们能直接放进去或嵌进去」，并选**完全嵌平**（槽深 = 零件底座高度）。
> 前提：06a / 06b **都还没打印**，可自由改。
> 结论：06a 新增 5 个嵌槽 + 删 2 处旧特征；06b 完全不动；总重 277.1 → **258.8 g**。

---

## 〇、v2 修正（领导指出锥形底问题后）

07 / 11 的底座是**倒四棱柱**（28→34 / 24→30），第一版用**直壁槽** → 口上留 1.2mm 环缝，缝底下是 3.6mm 宽的空腔，且"锥面自定心"的说法是**错的**（0.6 间隙下锥面根本碰不到槽壁）。

**v2 改法**：
- **07 / 11 改锥形槽**（与零件同角度：33.7° / 36.9°，单边 0.15）→ 口上缝 1.2 → **0.3**，缝里不再有腔体，零件仍坐在槽底
- **04 / 08 / LED 保持直壁**（它们本身就是直壁/平板），间隙由 0.6 收紧到 **0.25**（口上缝 0.6）
- 为什么其余三件不做成锥形底：04 是 10mm 空心裙墙（做锥度会把 3mm 壁削到 1.7），08 是 2mm 平板，LED 是买的成品 PCB 改不了

**v2 实测**（逐点探针）：07 表面槽宽 34.1 / 底 28.3；11 表面 30.1 / 底 24.3；06a 质量 261.3 g。

## 〇之二、v3 定版（加槽口倒角 + 08/11 微调）

- **槽口 0.6×45° 导入倒角**：给 04 / LED 两个直壁槽加了（07/11 锥形槽自带 33.7°/36.9° 导入，08 两侧墙只剩 1.4mm，不加）
- **08 从 (−75,8)→(−77,8) 且不转角**：转角 8° 时槽角会切进继电器槽 1.8mm；改成 0° 后左右各留 1.4mm 墙
- **LED 从 (−16,12.5)→(−14,12.5)**：原位置与 04 槽只隔 0.4，倒角会相交 → 留 1.0mm 墙
- 06a 定版 **261.1 g**（20% 填充 86.2 g），watertight / bodies=1

**踩坑记录**：① 倒角最初做成 1.6mm 高、顶面在 z=9，导致与相邻槽合并成非流形（3 条边）→ 定位到 08 槽角与 11 槽相切；② `continue` 写进字符串时被转义成 `/n`，脚本直接语法错误。

## 二、顺带删掉的两处

1. **LED φ5.2 通孔 (−22,18)**：改用模块嵌槽后无意义，且会跟槽穿通 → 删除。
2. **扎带槽 (−70,0)**：正好在 08 底座嵌槽范围内，留着会被槽穿通 → 删除（还剩 3 个：−140/−85、−140/0、−70/−85）。
