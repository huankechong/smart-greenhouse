## 一、已修的真 bug

### 🔴 B1 四个老槽的槽深全部多 1mm（切刀中心少加 1）

- **位置**：`base_2pc_models.py` 的 pot / breadboard / relay / tank 四处 `holes.append(C/B(...))`
- **成因**：切刀中心写成 `pt - depth/2`、高度 `depth+2` → 实际切到 `pt - depth - 1`，比设计深 1mm
- **实测证据**：花盆槽底 **0.95**（设计 2）、面包板 **3.45**（4.5）、继电器 **3.45**（4.5）、水箱 **1.95**（3）
- **影响**：四个大件比装配图低 1mm；**花盆槽底只剩 1mm 厚**（上坐 2~4kg 湿土，长期有下挠/开裂风险）
- **修复**：中心改 `pt + 1.0 - depth/2`，槽底 = `pt - depth`；修后实测 1.95 / 4.45 / 4.45 / 2.95 ✓
- **副作用**：06a 261.1 → **275.6 g**、06b 293.1 → **304.2 g**（料多了，但槽深对了）

### 🟠 B2 直壁嵌槽的间隙口径重复计算

- **位置**：`fits` 表 + 切刀 `fw + p["pocket_clear"]`
- **成因**：表里 04/LED 的 `fw` 已经写成了"零件+0.5"，切刀又加 0.6 → 实际 **0.55/边**；而 08 的 `fw` 写的是原始 30.0 → 0.3/边。**同一张表里两种口径**
- **影响**：04/LED 槽比文档（0.25/边）宽一倍，件会晃；文档与实物不符
- **修复**：新增 `fit_clear = 0.6`（单边 0.3），`fits` 一律存**零件真实尺寸** → 三个槽统一 0.3/边

### 🟠 B3 08 扎线座的槽按错误尺寸开（33×20，实为 30×16）

- **位置**：`fits` 表 `("08 扎线", ..., 33.5, 20.5, ...)`
- **成因**：凭记忆写了"30×16 + 3/4 余量"，把余量当成了外廓
- **影响**：槽比件大 4mm，件放进去来回晃，且会与继电器槽角相碰（曾触发非流形）
- **修复**：改回 30.0×16.0 + `fit_clear`
