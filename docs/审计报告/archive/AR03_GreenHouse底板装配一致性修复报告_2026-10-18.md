## 一、审计方法

这次不靠看图，也不靠"改过的件看起来对不对"，而是**把底板当作被查对象反向核对**：

1. **落座反查**：列出装配里每个 `z_min ≤ 板顶+1mm` 的件，取其底面高度，与该件"应该坐在哪"（槽底 / 板面）逐一对表。
   > 底板不是平板——花盆/水箱/面包板/继电器各有 1.5–4mm 的定位槽，件必须坐进槽底。
2. **干涉布尔**：件与底板做 `boolean.intersection`，体积应 < 5 mm³。
3. **空槽扫描**：底板上每个槽位，用 1mm 立方体 × 底板布尔求交判断"该处是实体还是空腔"，找出**开了槽却没东西**的区域，以及**该有槽却没有**的件。
4. 新写 `check_base_fit.py` 固化以上三项，改任何参数重跑即可自查。

> 方法论修正：`trimesh` 的 `mesh.contains()` 射线法对 STL 不可靠；`Path.section().to_planar()` 会**替换坐标系**，拿它判断"点在不在实体内"必然错。最终改用 **1mm 探针盒布尔求交**（体积 ≈ 1 mm³ 即实体），才不会骗人。

## 二、审计结论总览

| 项 | 结果 |
|---|---|
| 落座高度 | 查出 **3 类共 5 件**错位（1 件陷进板、4 件浮空） |
| 件 × 底板干涉 | 1 处（水箱陷 1mm），修后全 0.0 mm³ |
| 空槽 | **1 个**（ESP32 槽，55.6×28.6，一直空着） |
| 缺失特征 | **1 个**（裸 LED 没有任何安装位） |
| 文档 | 底板/装配两份说明同步更新，左片重量 228.8 → 233.6 g |

**结论：底板不是"没更新"，是从来没和装配对齐过。** 之前几轮我只改了零件和摆放，底板的槽位一直停在第一版布局。

## 三、问题明细与修复

### 🔴 高危 1 项：ESP32 槽是空槽

| 项 | 内容 |
|---|---|
| 位置 | 左片 (−45, 98)，55.6 × 28.6 × 1.5 深 |
| 成因 | 首版布局里 ESP32 独立定位；后来装配把它放到面包板上（`build_assembly.py` 第 230 行，`(−100,−50)`），底板没跟着改 |
| 影响 | ① 板面上一个 55.6×28.6 的凹坑白占位置，正对 OLED 支架背面，答辩俯视图一眼能看出"少个件"；② 若照图施工，会误以为 ESP32 该放那里，而那个位置在屏幕正后方，装上会挡屏 |
| 修复 | **删除该槽**（`base_2pc_models.py`：去掉 `esp_w/esp_h/esp_pos` 与对应的 pocket 循环项） |

> 为什么删槽而不是把 ESP32 搬过去：ESP32 插在 400 孔面包板上，靠两排排针定位，比躺在 1.5mm 浅槽里稳得多；而且它要接面包板跳线，放远了线更长。槽本身就是多余的。

### 🔴 高危 1 项：裸 LED 无安装位

| 项 | 内容 |
|---|---|
| 位置 | 左片 (−22, 18) |
| 成因 | 上一轮取消灯罩（无半透明耗材）后，LED 从"罩在灯罩里"变成"裸灯珠立着"，但底板从未开过孔 |
| 影响 | 状态灯无处固定，只能靠胶带/悬空；整机唯一的状态指示失效 |
| 修复 | 新增 **φ5.2 通孔**（全穿 6mm），座圈（φ5.9）坐在板面，两根引脚（间距 2.54 < 5.2）从孔里穿到底面接线；装配里灯体/座圈高度同步改为 6.9 / 6.0 |

### 🟡 中危 1 项：水箱陷进底板 1 mm

| 项 | 内容 |
|---|---|
| 位置 | 右片水箱槽，深 3（槽底 z=3），装配把水箱放在 z=2 |
| 影响 | 水箱底面沉进底板 1mm，实际装配会顶住（真实瓶子放不平，且整机高度少算 1mm） |
| 修复 | 水箱组整体 +1：水箱 z=3、水体 z=6、水泵座 z=6、泵体/泵头 +1、水管起点 38 → 39 |

### 🟡 中危 2 项：面包板/继电器浮在槽上方 1.5 mm

| 项 | 内容 |
|---|---|
| 位置 | 槽底 z=4.5，装配放在 z=6.0（ESP32 随面包板一起浮） |
| 影响 | 槽的意义全丢——槽是定位用的，件不进去等于白开；俯视图能看到槽壁与件之间一圈 0.3mm 的缝，像没装好 |
| 修复 | 引入 `SEAT = PT − 1.5`，面包板/ESP32/继电器统一坐在 4.5 |

### 📄 文档 2 处

1. 底板说明：布局表删 ESP32 行、加 LED 孔行；重量 228.8 → **233.6 g**（20% 填充 ~77 g）；已知限制补 "ESP32 无独立槽"、"LED 孔需点胶" 两条；版本升 **v1.1**。
2. 装配说明：新增「落座高度」小节（6 行表 + 说明）；LED 行由"灯罩"改为"裸 LED 插孔"；水管起点 z=38 → 39。
3. `audit.py` 的底盘左片基准值同步 228.8 → 233.6（否则审计自己报错）。

## 五、已知限制（保留不修）

1. **花盆定位槽 φ62 vs 盆底 φ58**（单边 2mm 余量）。偏松，但实物花盆没量之前不敢收紧——宁可松，松了垫纸片就能居中；紧了装不进去。
2. **DHT11 座没有定位槽**：它自带 35×34 底板，坐平面即可；若开槽，左缘会与面包板槽壁只剩 0.2mm，必破。
3. **扎线座同样无槽**，靠 3mm 厚底座自重 + 线束张力。
4. LED 孔是"座圈坐在板面"的插孔式，不是过盈卡扣，**需一滴热熔胶**——5mm LED 的座圈 φ5.9 过不了 φ5.2 孔，做不了纯过盈。
