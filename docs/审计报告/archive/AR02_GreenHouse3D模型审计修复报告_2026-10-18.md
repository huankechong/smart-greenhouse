## 三、问题明细与修复

### 🔴 高危 2 项

**A-1　OLED 屏的盒子朝向错了，屏以 27.3mm 厚扎进支架（干涉 1192 mm³）**

- 位置：`build_assembly.py` 中 `scr = box([27.3, 1.6, 27.3])`
- 成因：绕 X 转 −45° 后，局部 Y 轴指向**斜面内**、局部 Z 轴指向**法线**。原写法把 1.6 给了 Y、27.3 给了 Z，等于把屏"立起来"当楔子插进去。
- 影响：装配图里屏面看不见，屏体穿透支架。
- 修复：改 `box([27.3, 27.3, 1.6])`，并把定位点从错误的 `y−5, z+15`（那是旧楔块几何的中心，重写后斜面中心已移到 `y+1, z+15`）改为沿法线内缩 0.8mm 的正确位置。
- 验证：干涉 1192.5 → **0**

**A-2　水管穿过水箱壁和花盆壁**

- 位置：`tube_pts` 折线
- 成因：①水箱壁顶 z=62，管子在 x=26 处高度只有 51，直接从壁里穿过去（91 mm³）；②在花盆一侧，管子从内侧擦过盆壁（202 mm³）。
- 修复：越壁段抬到 z=70；进盆段改为先越过盆沿（z=87 以上）再向内收。
- 验证：水箱×管 91.3→**0**，花盆×管 202.1→**0**，泵座×管 418.1→**0**，泵×管 267.4→**0**

### 🟡 中危 3 项

**A-3　水管与管夹对不上，管子贴着孔边切过夹体（1183 mm³）**

- 成因：我按"管孔在夹子局部 y=8"算坐标，实际参数 `ring_y=12`，偏差 4mm。
- 修复：孔心世界坐标重算为夹子原点 + `R(−20°)·(0,12)` = (+4.10, +11.28)，管子改为垂直穿过孔心。
- 验证：1183.6 → 717.3 → 471.3（残余为卡口过盈接触，见"已知限制"）

**A-4　土壤顶穿花盆内壁（1492 mm³）**

- 成因：土柱半径写死 35，而花盆内壁在土面高度处半径只有 35.7、盆口 37，斜壁处直接穿模。
- 修复：土柱半径改 33（在所有高度都小于内壁半径）。
- 验证：1492.5 → **0**

**A-5　DHT11 模块埋进托盘（1119 mm³）**

- 成因：模块 z 中心按 `PT+55+4` 放，而托盘顶面在 `PT+55+5`、槽底在 `PT+55+2.5`，模块 7mm 厚有一半沉在槽底以下。
- 修复：z 中心改 `PT+55+9`，模块底面正好坐在槽底。
- 验证：1119.0 → **0**

### 🟢 已修 1 项（低）

**A-6　水管起点在水泵座壁内（418 mm³）** — 起点 z 在座筒高度范围内且半径落在座壁里。改为从泵顶 `z=38` 起步。已并入 A-2 的验证。

### 📄 文档错 1 处

**A-7　底盘交付说明里连接块单件重量写 2.5 g，实际 4.9 g**

- 位置：`outputs/3D打印件/花房3D_整机底盘/交付说明_整机底盘两片式v1.md` 交付清单表
- 成因：我把"×2 件合计"的心算值写进了单件栏。
- 修复：改 4.9 g/个（20% 填充实际 ~1.6 g/个，该项原本正确）。

### 📌 补记：上轮已修的严重缺陷

**A-0　件 1 传感器板槽封底 + 锥度太宽**（14:00 装配时发现，非本次审计）

- 锥形槽 2.4→1.8 的窄口仍宽于 1.6 的板 → 永远夹不住；槽底封在 z=8 → 板子顶住下不去，传感器头进不了土。
- 已改为恒 1.5mm 过盈槽、槽贯通底板。P0 STL 重生成（22.8 → 23.4 g），文档同步。

## 五、已知限制（保留不修，答辩可讲）

以下干涉是**设计意图或物理正确**，不是错误：

| 配对 | 体积 | 说明 |
|---|---|---|
| 水体 × 水泵 / 水泵固定座 | 19249 / 13668 | 水泵本来就泡在水里 |
| 土壤 × 传感器板 | 515 | 探针本来就插在土里 |
| 传感器支架 × 传感器板 | 108 | 板槽 1.5 vs 板 1.6 = 0.1mm 过盈，靠它夹紧 |
| 土壤 × 水管 | 7 | 出水口贴着土面 |
| 土壤 × 水管末端夹 | 313 | 夹子下缘没入土面，视觉上被土挡住 |
| 水管 × 水管末端夹 | 471 | 卡口压入管壁 |
| 主茎/叶片之间 | 2.6–27.8 | 植株是示意形态，允许自交 |

另外两条非几何限制：

1. **装配图不代表真实装配公差**：它是示意图，件与件之间按标称尺寸摆放，没有留 0.2–0.3mm 打印公差。
2. **`audit.py` 只查穿模，不查壁厚**：最小壁厚仍是靠参数设计保证（打印件除灯罩 1.6 外全部 ≥2mm，已在各批文档标注）。
