## 一、动手前的核对结论

先查了一遍「示意图与 STL 是否已经不同步」，结论是**几何完全同源**：

| 对象 | 体积 | 外形 |
|---|---|---|
| `01b_sensor_rim_hook_v1.stl` | 19417.1 mm³ | 30 × 32.64 × 49.14 |
| 脚本 `build()` 重建（落床） | 19417.1 mm³ | 30 × 32.64 × 49.14 |
| 装配示意里的实件 | 19417.1 mm³ | 同（仅旋转） |

也就是：**示意图画的就是这个 STL**，AR05 的四项优化（管夹 03 v2 / 水管路径 / OLED 卡爪 / 底盘漏水）没有碰它。

真正落后的是**设计语言**——AR05 把管夹改成了「盆沿双爪、爪只下探 7mm、不入土」，而 01b 仍是旧方案：长斜臂 46mm、埋土 35mm、夹爪 16mm 深、爪宽 14mm。所以本次按新示意图的构造重做，而不是重出旧版。

## 二、v1 的三个实际缺陷

| # | 问题 | 后果 |
|---|---|---|
| 1 | 斜臂埋土 35mm（挂钩×土壤 **11522 mm³**） | 必须**先卡盆沿再填土**；装完土不能调插入深度，也取不下来 |
| 2 | 夹爪 16mm 深、14mm 宽、夹口 5.6 | 与 AR05 双爪（7mm / 20mm / 6.2）不是一套，盆沿上两种画风 |
| 3 | 长斜臂是打印时的"第三条腿" | 打印姿态靠臂尖落地，夹爪悬空 28–42mm，实际需要支撑（文档写"免支撑"是错的） |

## 三、v2 结构

```
        夹板柱（30×12×21，板槽 23.6×1.5 斜 8° 贯穿）
              │
        ┌─────┴─────┐  ← 顶桥（30×19.8×6，跨过盆沿并向盆内伸出）
        │           │
      外爪         内爪          各 20×3.5×7，随盆壁锥度 8.1° 下探，爪底 z=-7
     （盆外）    （盆内）         土面在 z=-8 → 爪不入土
```

- **板从上方插入**，穿过夹板柱的 8° 斜槽，再经顶桥上的开口进入盆内土壤；
- **板顶与夹板柱顶面齐平**即为插入深度基准（板长 98、入土 67mm、露出盆沿 22mm）；
- 顶桥中间为贯穿斜槽，两侧各留 **3.2mm 侧壁**（不切穿，仍是单体）；
- 打印姿态：两爪落地、顶桥在上跨接、夹板柱再往上堆，**全垂直壁，真的免支撑**。

## 五、开发中踩的四个坑（都留了痕）

1. **内爪悬空成独立块**：夹爪 20 宽、导轨在 X±12.2 之外，两者不相交 → `bodies=2`。改过一版把内爪加宽到 25.2 去够导轨，结果**爪端切进盆壁**（X=12.6 处壁面在 y=−4.7，正落在爪的 Y 区间里），干涉 44.5 mm³。
2. **夹口 4.6 会啃盆壁**：实测 4.6 → 21.9 mm³、5.0 → 8.7、5.2 → 4.1、**5.6 → 0**。最终取 5.6（壁厚 4 + 1.6 余量），与 v1 一致。
3. **"两根导轨 + 中间留板道"方案整体作废**：板道必须绕过盆沿的圆弧，导轨要么够不到内爪、要么加宽后与板道冲突。最终改成**整块顶桥 + 贯穿斜槽**，问题一次消失。
4. **板被定位到槽心而不是板心**：`board_mesh` 拿到的是槽心，直接居中会让板整体抬高 37mm（板顶跑到盆沿上 64mm）。改成沿槽轴线按目标高度解参数 `t`，板顶才落回夹板柱顶面。

## 六、已知限制（v2 相对 v1 的取舍）

1. **板下部 70mm 无支撑**：v1 靠斜臂撑住，v2 只靠夹板柱夹 21mm，下面靠土壤扶正。**移动整机时板会晃**——浇水时不受影响，搬动前建议先取板。
2. **夹口 5.6 是照模型盆**（壁 4.0）：实物到手按 `实测壁厚 + 1.2` 改 `rim_gap`。
3. **板槽按板厚 1.6 做 0.1 过盈**：实测板厚差 0.1 以上要重跑（`board_t`）。
4. 顶桥向盆内悬伸约 7.7mm（打印时属小悬臂，可能有轻微下垂），实物首件留意桥面是否平。
