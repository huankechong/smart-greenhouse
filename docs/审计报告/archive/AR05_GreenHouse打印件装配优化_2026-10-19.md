# AR05 · 花房 3D 打印件按整机示意模型优化

- **触发**：2026-10-19 领导指示「根据示意模型，优化需要打印的模型」
- **方法**：以 `build_assembly.py` 装配模型为基准，跑 `audit.py` 两两布尔求交做基线，逐项定位真实干涉，改参数化脚本（不改 STL），全链验证
- **结论**：4 项优化全部落地；打印件与花盆/土壤干涉清零，水管穿夹从 471 → 1.2 mm³；12 个 STL 自检全 OK；HTML 无 JS 错误

## 二、优化项与实施

### 1. 管夹 03 重设计（v1 → v2，盆沿双爪式）

**为什么推翻原设计**：原「立板跨盆壁 + 锥形楔紧槽」依赖盆壁为直壁，锥形盆上必然咬入。01b 传感器挂钩已证明「双爪随锥度下探」在锥形盆上干涉为 0，直接复刻该原理。

| 项 | v1 | v2 |
|---|---|---|
| 夹持方式 | 单板 + 锥形楔紧槽（下 7.5 → 上 4.5） | 内外双爪，随盆壁锥度 8.5° 下探 |
| 爪入土 | 18mm 深，埋土 381 mm³ | **7mm（土面在盆沿下 8mm），不入土** |
| 管孔位置 | 平台上方，管斜穿出 | 桥面上方独立管环柱，孔中心内移 11mm（避开内爪同域） |
| 落床 | z_min=0 | 归一化 z_min=0，`metadata["rim_top_z"]` 供装配补偿 |
| 体积/重量 | 6.9 g | 11.8 g（多出的料是双爪 + 管环柱，换掉 381 mm³ 埋土） |

**参数改动**（`p0_models.py` → `PARAMS["clip"]`）：`rim_gap 5.6→6.2`、`ring_y_local -6→-11`、`taper 8.5`、`jaw_down 7.0`、`col_h 20`。

### 2. 装配水管路径重排

孔轴改为垂直贯穿后，管路径改为**高空绕行 → 柱顶正上方 → 竖直下穿**，弯头全部在管环以外：
`泵顶 (85,8,39) → (85,8,58) → (58,8,70) → (15,14,76) → (-30,35,92) → (-58,50,118) → (-58,55,126) → (孔轴,126) → (孔轴,81)`
出水口悬停土面 2mm（土面 z=79）。

### 3. OLED 支架 04 加防脱卡爪（落实 P1P2 限制 3）

槽上坡端两只 1.2mm 厚、4mm 宽弹性爪，向槽内悬伸 1.5mm 压住板上缘（0.6 过盈，PLA 弹性扣入）。三角面 44 → 92，重量 21.1 g 不变。

### 4. 底盘 06a/06b 漏水防护（落实底盘限制 7）

| 改动 | 几何 | 作用 |
|---|---|---|
| 槽底排水孔 | φ5 @(120, 52)，通板 | 水箱漏的水穿板直落桌面，不进电控区 |
| 挡水堤 ×2 | 3×3mm 堤：水箱槽 -Y 边（120 长）+ 接缝侧 -X 边（98 长），右片 | 拦住横向漫流 |
| 影响 | 06b bbox z 8 → **11mm**（堤高），实体 274.3 → 276.7 g | 打印高度 +3mm，料几乎不变 |
