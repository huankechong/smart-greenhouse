## 三、本轮重审新发现的问题（3 项，均已修）

### 🔴 R-1｜我的"硬停机"逻辑引入新风险：停机时继电器仍在高阻

- **位置**：`GreenHouse_v1.ino` setup（修复前：停机在 446 行，继电器锁定在 480 行之后）
- **成因**：我把"标定非法 → 停机"插在标定检查处，而**继电器电平锁定原本在后面**
- **影响链**（这正是 AR16 P0-2 想防的场景，却被修复本身放大）：
  1. `EN_WATER=1` + 标定值填错 → 走到停机分支
  2. 此时 `PIN_RELAY` **尚未 pinMode(OUTPUT)、尚未锁电平** → 引脚高阻
  3. 低电平触发的继电器模块若内部上拉不足，可能误吸合 → **泵一直转，且程序已挂起无人切断**
  4. 这是"停机保护"变成"持续出水"的最坏情况
- **修复**：把继电器锁定**前移到 `Serial.begin()` 之后第一件事**（现 432 行），早于一切可能停机的检查
- **验证**：`grep` 确认顺序 432（继电器锁）< 453（标定停机）；双形态编译通过
- **优先级**：**P0（已完成）**

> 📌 **教训**：加"提前退出/停机"类保护时，**必须先确认所有执行器已处于安全态**，否则保护逻辑本身会制造危险窗口。

### 🟡 R-2｜`requirements.txt` 的 trimesh 约束与实际不符（我自己写错的）

- **位置**：`requirements.txt` 第 5 行
- **成因**：我凭印象写 `trimesh>=4.0,<5`，未核对实装版本
- **影响**：按清单执行 `pip install -r requirements.txt` 会**把 trimesh 从 5.1.1 降级到 4.x** → 现有建模脚本可能因 API 差异失败。**清单本意是保证可复现，写错反而制造不可复现**
- **修复**：改为 `trimesh>=5.1,<6`（匹配实测 5.1.1）
- **验证**：写脚本逐包比对"约束 vs 实装"，现 5 个包**全部满足**
- **优先级**：P1（已完成）

> 📌 **教训**：**依赖清单必须由"实测环境"反推，不能凭记忆写**。本次靠"写完立刻校验"抓到，否则等到换机才发现。

### 🟡 R-3｜文档版本号全面滞后（v1.5.1 → 实际 v1.6）

- **位置**：`AGENTS.md` §50/§105、`README.md` §13、`docs/index.md` §18、`docs/W1到货点火与标定操作指南` §227/§236

## 四、对 AR16 结论的更正（2 条，重要）

### 更正 1｜P0-1 的"`to_planar` 定时炸弹"**归因错误，不成立**

- AR16 原话：「`trimesh` 的 `to_planar` 2026-01-01 会移除，届时建模脚本全线崩」
- **实际核查**：
  - `grep -rn "to_planar" outputs/**/*.py` → **项目代码 0 处调用**（只有 `check_base_fit.py:117` 一行注释提到它）
  - `hasattr(trimesh.path.path.Path, 'to_planar')` → **False**，当前 trimesh 5.1.1 **已移除该方法**
  - 我看到的 DeprecationWarning 来自**我自己写的临时验证脚本**（`/tmp/ray_check.py` 等），**不是项目代码**
- **更正结论**：项目代码**不受影响**，不构成风险。原 AR16 该条应降为"信息性提示"。
- **保留价值**：`requirements.txt` 里已注明"本项目不使用 to_planar，正式脚本一律用 to_2D()"，防止未来误用。

### 更正 2｜P1-2「import 即建模导致校验慢几十秒」**严重度高估**

- AR16 原话：「5 个校验脚本每次重建 88 个几何体 → 每次校验几十秒」
- **实测**：`import build_assembly` 耗时 **1.5 秒**（88 几何体）
- **原因**：AO 有磁盘缓存（`ao_cache.npz`），几何构建本身很快；AR16 把"完整 `build_assembly.py` 跑一遍 6–8 分钟"（含 AO 烘焙 + 出图）误当成 import 耗时
- **更正严重度**：🔴 高 → 🟢 低（纯代码整洁性问题，非性能瓶颈）
- **仍建议改**（但不急）：`if __name__` 隔离 + 几何 pickle 缓存，可把 1.5 秒降到 0.3 秒。**建议首版试装后做**，现在改 500 行模块级代码风险 > 收益。
