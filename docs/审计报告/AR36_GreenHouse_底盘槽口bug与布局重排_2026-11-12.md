# AR36 · 06a 底盘槽口 bug 修复 + 布局重排

日期：2026-11-12
涉及：`outputs/3D打印件/花房3D_整机底盘/base_2pc_models.py`、`花房3D_整机装配/build_assembly.py`、`check_base_fit.py`

## 一、修复的真实缺陷

### 1. 小件嵌槽槽口被切成正方形（严重）

`base_2pc_models.py` 的槽口导入斜口用了同一变量：

```python
h0 = (fw + fit_clear) / 2.0                # 只算宽度的一半
v = [[-h0, -h0, ...], [h0, h0, ...]]       # X、Y 都用了 h0
```

后果（逐层实测）：

| 槽 | 槽本体 | 槽口（错误） |
|---|---|---|
| 08 理线 | 30.2 × 16.2 | **31.2 × 31.2 方形** |
| LED | 19.0 × 13.6 | **20.0 × 20.0 方形** |

→ 任何矩形件都盖不满，出现"方口 + 大台阶"。

**修复**：`hx`/`hy` 分别按宽、深计算；后来按领导决定直接改成**直口**（`mouth_chamfer: 0`），彻底取消槽口斜口。

### 2. 06c 沉槽深 1mm（严重）

切槽盒 `recess_d + 2` 以 `pt − recess_d/2` 为中心 → 槽深 4.5（应 3.5），连接块沉下去 1mm 不齐平。
修复：高度改 `recess_d + 1`、中心上抬 0.5 → 实测槽深 **3.50**、块顶与板面差 **0.00**。

### 3. 07 DHT 与面包板槽几乎穿通（0.6mm）

顺带拉开到 10.6mm。

### 4. LED 参数是死代码

`led_d: 5.2` / `led_pos` 定义了但从未使用 → 底盘上**没有** φ5.2 灯孔。LED 只能走 18.8×13.5 的模块槽，已按此做了 12 号座。
