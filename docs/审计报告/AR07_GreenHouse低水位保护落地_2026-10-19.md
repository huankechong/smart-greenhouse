## 一、问题起源：文档说了代码没做的事

领导一句话戳破：**没装水位传感器，"低水位停泵"是怎么实现的？**

核查固件源码的结论：低水位保护是**"代码钩子就绪、硬件未装、开关关闭"**三态叠加——
`EN_LEVEL` 默认 0，整块 `#if EN_LEVEL` 在预处理阶段被裁掉，编译产物里连 GPIO32 的
读取语句都不存在。当时真在跑的只有"连浇 6 轮 + 冷却 10 分钟"这条纯软件保护。

根因：交接文档把"低水位停泵"与"连浇上限"并列写成 v1.2 已完成能力，**没标注需要
外接传感器**。教训已入 AGENTS.md：能力清单必须区分「已生效 / 需硬件才生效 / 仅代码预留」。

## 二、选型链（全程有据，每步都有关停理由）

| 决策点 | 结论 | 依据 |
|---|---|---|
| 传感器形态 | 干簧管浮球开关，弃电阻式雨滴板 | 雨滴板隔瓶壁测不到、浸水长期电解；干接点无极性、寿命百万次 |
| 水箱 | 1L PP 打包桶（满口 1200ml，¥1.55×5） | 唯一有官方尺寸图的档位：底 φ106 < 底盘槽 120.6 ✓，内高 101 放得下短杆浮球 |
| 型号 | **P52**（非最初 P43） | 领导澄清 43mm 是"两箭头间有效长度"→ 重算：P43 报警点 67mm、剩 578ml < 单轮上限 650ml；**P52 报警点 52mm、剩 700ml，且便宜 ¥0.4** |
| 电压档 | 0~110V（非 220V） | 220V 版触点间隙大、需更强磁场，小信号干电路下灵敏度反而差；110V 款是洗衣机/净水器 MCU 量级 |
| 螺纹 | M10（卖家确认） | 开孔 φ10.5；六角对角 19.6 → 凸台 φ20 |
| 触点 | 常开（浮起闭合） | fail-safe：没水/断线 → 上拉读 HIGH → 判"没水" → 停泵。坏的方向是停水不是淹水 |
| 上拉 | **1kΩ 外部**（非 10kΩ/内部） | 干簧管湿电流门槛 1–10mA：1kΩ@3.3V=3.3mA ✓；10kΩ=0.33mA ✗ 会触点氧化后时通时断 |
| 垫片 | 不要 | φ20×0.8 打印凸台替代；M10 螺母（随货）单侧锁紧 |

## 三、固件 v1.4 改动（`GreenHouse_v1.ino`）

| 项 | v1.3 及以前 | v1.4 |
|---|---|---|
| 水位输入 | 模拟量比阈值 `LEVEL_DRY_RAW`（雨滴板） | **干接点数字读取**（浮球） |
| 采样 | 每 loop 直读 | 100ms 节流 + **连续 3 次一致**才采信（水面波动消抖） |
| 极性 | 写死比较方向 | `LEVEL_WET_CLOSED` 宏，常开/常闭改一个宏适配 |
| 首启 | 可能未判稳就开泵 | `gLevelReady` 标志：首次稳定判定前**拒绝启动浇水** |
| 引脚注释 | 第 09 件盖板 + P43 | 第 10 件替换盖 + P52（本轮同步改） |

**编译验证（arduino-cli · esp32:esp32:esp32 2.0.17，实跑）**：

| 配置 | Flash | RAM |
|---|---|---|
| EN_LEVEL=0（全关，日常烧录） | 269,517 B（20%） | 21,592 B（6%） |
| EN_LEVEL=1（浮球启用） | 270,145 B（20%） | 21,600 B（6%） |

踩坑记录：首跑报 `undefined reference uart*` 一片——是 `/tmp/b_off` 陈旧构建缓存
（core.a 与核心版本不匹配），`rm -rf` 重建即过，**不是代码问题**。arduino-cli 实际
路径在 IDE 安装目录内（`D:/Appdata/arduino-ide/.../resources/arduino-cli.exe`）。

## 四、第 10 件：水箱替换盖（`outputs/花房3D_水箱盖/`）

为"桶不打孔"而生：φ142.4×4 盖板 + 裙边 φ136.8×8 套桶口 + φ20×0.8 螺母凸台
（替代垫片）+ 三孔（φ10.5 浮球中心 / φ10 水管 −Y22 / φ8 过线 **−Y45**，2026-10-20 由 +Y30 移至 −Y 同侧，见 AR09）+ 双指位缺口。

关键校验（`check_geometry()` 参数反算，非目测）：孔间距 ≥11.75、浮球杆尖距泵顶
134.5mm、watertight / 单体 / z0 全过；41,224mm³ ≈ 51g PLA，首层整圆免支撑。

容量账（P52 定版的最终依据）：报警剩 700ml > 单轮上限 650ml；P43 只有 578ml 不够。

细节见同目录《交付说明_水箱替换盖v1.md》。

## 五、接线规划表同步（第 8 节新增）

雨滴模块节保留留档，新增"浮球开关"一节：购物信息、2 线接线（GPIO32 + GND，
1kΩ 上拉 3V3→GPIO32，100nF 并联）、**电平账**（有水闭合读 LOW=正常；没水/断线读
HIGH=判低）、安装三步、万用表验收三步、故障速查 3 条；红线 1（GPIO32 改配浮球）、
通电自查清单、第六节故障表各加对应条目。

**中途自查抓到并修正 1 个错**：初稿把浮球"线 2"写成接 3V3——与固件电平账矛盾
（上拉在 3V3，开关必须到 GND 才能拉低）。教训：写文档要拿固件源码对电平，不能凭印象。
