## 三、⚠️ 已作废并更正：4 颗器件实为**万可 WAGO 221 快接端子**

> **本节初版判断为「插座底座」，属误判 —— 已于 2026-10-23 19:05 被领导指正，并经联网查证推翻。**
> **更正后的结论：这 4 颗是万可（WAGO）221 系列快接端子，不是继电器，也不是继电器插座底座。**
> **初版判断原文保留在 §3.5 供追溯。**

### 3.1 更正依据：标签与 WAGO 221-413 官方规格逐条对上

| 标签 OCR 所得 | WAGO 官方规格（wago.com 221-413） | 判定 |
|---|---|---|
| `AWG 24-12` | 24–12 AWG | ✅ 完全一致 |
| `0.14/0.2-4` | 细线 0.14–4 mm² / 硬线 0.2–4 mm² | ✅ 完全一致 |
| `450V/32A` | 额定电压 450 V、额定电流 32 A（IEC 60664 / EN 60998） | ✅ 完全一致 |
| `SET 20A` | UL 486C 认证下额定电流 20 A（UL 侧电压 600 V） | ✅ 完全一致 |
| `Cu 1.6/2` | 镀锡铜导电条（tinned current bars） | ✅ 导体材质标注 |
| 透明壳 + 橙色拨杆 | housing: transparent / actuator color: orange | ✅ 完全一致 |
| UL 认证标志 | UL 486C Approvals | ✅ 完全一致 |

### 3.2 这 4 颗在项目里的真正用途

| 项 | 内容 |
|---|---|
| 型号 | **221-413**（3 线位 / 一进二出 / 三通节点）—— 与借用清单 2.2 中 10/19 自购的"WAGO 221-413 ×2（泵回路三通节点）"**对上了** |
| 规格 | 450 V / 32 A，导线 0.14–4 mm²（24–12 AWG），剥线长度 **11 mm** |
| 尺寸 | 18.8 × 8.4 × 18.6 mm，单只 2.5 g |
| 数量 | **4 只**（清单原计划 2 只 → **超量**，可能 412/413 各 2，只数待清点） |

**泵回路两个三通节点**（+5V 汇流、GND 汇流）**的接线端子现已实物在手** —— 这是 10/19 自购单里唯一还没确认到货的一项，现已确认。

### 3.3 顺带解决的两件事

1. **免焊方案 B 现在实物可行** —— `docs/W1无烙铁接线方案_2026-10-20.md` 的方案 B（硬芯线 + WAGO 221）原本依赖"10/19 已下单、待到货"，现在端子已到。**万一电烙铁借不到，这条路立刻能走。**
2. **继电器的问题回到原点** —— 这 4 颗既然不是继电器，那"套件第 16 项继电器模块在不在"这个问题**仍然没有答案**，需要翻找未拍的袋子（见 §六 行动项 1）。

### 3.4 错在哪（方法论复盘）

| 环节 | 初版做法 | 问题 |
|---|---|---|
| 识别路径 | 看到「透明壳 + 金属簧片 + 触点额定值」→ 套到"继电器底座"模板 | **没有先查商标**。标签上印着 `UL` 认证标志却没去查这家是谁的产品 |
| 关键线索漏读 | 标签印 `AWG 24-12`（适用线径） | 当时把它当成"底座才有的特征"，实际**这正是 WAGO 快接端子的核心卖点**（一款覆盖各种线径的通用端子必然标线径） |
| 颜色当成特征 | 橙色 = 触点/铜件 | 实际**橙色是 WAGO 221 系列的标志色（拨杆）** |
| 结论固化太快 | 看到"电路符号"就认定是继电器原理图 | 那是 WAGO 端子上的**接线示意图**（哪个孔接哪根线），不是继电器符号 |

### 3.5 初版判断原文（保留供追溯，已作废）

> **以下为初版（18:36–19:00）判断，现已作废：**
>
> 「4 颗'继电器'经 8× 放大确认是**插座底座（socket）不是继电器模块** —— 壳内无 PCB，只有金属簧片 + 橙色标签；标签印的是 `Cu 1.6/2` / `AWG 24-12 0.14/0.2-4` / `20A 300V` / `450V 32A` 这类**接线规格**（只有底座才标线径），带 UL+PSE 认证。
> **插座底座不能直接接 ESP32 GPIO**（线圈电流 30–90mA 会烧 IO），必须先翻找套件里有没有带 PCB+光耦的继电器模块（套件第 16 项，48 件只拍了 4 袋）；若无则三选一：换光耦隔离 MOS 管模块（3–5 元，接口与继电器模块一致，**推荐**）/ 自搭三极管驱动（要多焊 3 点且改主程序引脚逻辑）/ 用底座+本体+驱动电路。
> ⛔ **核实前不要接泵回路。**」

**作废原因**：把 WAGO 通用快接端子误判为继电器插座底座。**教训：认器件先查品牌与型号，再看结构；标签上的认证标志是查证入口，不是装饰。**

### 方法论教训

1. **认器件先查品牌，不要先套结构模板。** 标签上有 UL 认证标志 → 先查这家是谁的产品，而不是从"透明壳+金属簧片"倒推品类。
2. **"某个特征只有某类产品才有"这种推理最危险** —— 我当时认定"只有继电器底座才标线径"，实际上一款覆盖各种线径的通用快接端子**必然**标线径。特征要双向验证，不能单向排除。
3. **颜色不是鉴别特征** —— 橙色在 WAGO 221 是拨杆的颜色，不是"铜触点"。
4. **领导指正时先查证再改口** —— 本次是领导指正 + 官方规格 7/7 对上，两个独立来源互相印证才落笔。
