## 三、⚠️ 专项核实：4 颗"继电器"是**插座底座**，不是继电器模块

### 3.1 观察证据（8× 超放大，两组各 2 颗，结论一致）

| 观察项 | 实拍所见 | 推论 |
|---|---|---|
| 壳内 PCB | ❌ **没有**绿色或蓝色电路板 | 排除「继电器模块」 |
| 壳内结构 | 仅金属簧片 + 橙色标签纸 | **插座底座（socket）** |
| 标签文字 A | `Cu 1.6/2` `SET 20A 300V` | 铜接线柱截面 + 触点额定 |
| 标签文字 B | `AWG 24-12` `0.14/0.2-4` `450V/32A` | **适用导线线径范围** —— 只有底座才标这个 |
| 认证标识 | UL（美国）+ PSE（日本） | 正规工业件 |

### 3.2 为什么这个区分很重要

「继电器模块」= PCB + 光耦隔离 + 驱动三极管 + 3 个螺丝端子（IN / GND / COM-NO-NC）
→ **ESP32 GPIO 直接接 IN 脚即可**，5V 供电，逻辑低电平触发。**主程序现有逻辑不用改。**

「继电器插座底座」= 纯被动件，5 个脚是给**继电器本体**插的
→ **不能直接接 ESP32 GPIO**（线圈电流 30–90mA 会烧 IO），必须额外搭驱动电路。

### 3.3 三种应对

| 方案 | 做法 | 成本 | 改动 |
|---|---|---|---|
| **① 先找齐模块**（首选） | 套件共 48 件，本次只拍了部分袋子，翻找第 16 项「继电器模块」（带 PCB + 光耦 + 螺丝端子） | 0 元 | **无**（直接用） |
| ② 底座 + 本体 + 三极管 | 自搭驱动（S8050 或光耦），要多焊 3 个点 | 0–2 元 | 主程序引脚逻辑要改 |
| ③ 换 MOSFET 模块 | 淘宝「光耦隔离 MOS 管模块」 | 3–5 元 | **无**（接口与继电器模块一致） |

### 3.4 风险提示

> ⛔ **核实前不要接泵回路。** 把插座底座当模块接到 ESP32 上 → GPIO 直接承受线圈电流 → 烧 IO 甚至烧板。
> ⛔ 也**不要在没核实前下结论说"套件没继电器"** —— 48 件套件只拍了 4 袋，模块本体很可能在未拍的袋子里。
