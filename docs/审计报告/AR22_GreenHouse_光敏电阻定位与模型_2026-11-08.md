# AR22 · 光敏电阻新增定位与模型（2026-11-08）

> 触发：领导问「光敏电阻你要放在哪里」。
> 背景：固件从 v1.x 起就**一直在读** `PIN_LIGHT 35`（串口 `[数据]`、巴法云、网页、OLED 四处都显示），但 3D 装配里从没给它位置、接线表也只写"可选"。**不装 = 读到悬空值**，OLED 上那行"光照"是假数据。
> 结论：新增第 10 件 **11_ldr_stand**，装花盆脚边 (-110, -5)。

---

## 一、为什么是 (-110, -5)

| 约束 | 核查 |
|---|---|
| 上方无遮挡 | 屏架 (-45,38) / DHT 托盘 (-45,-60) / 水箱 (85,32) 都不在它头顶；花盆在 y≥19，只挡身后 |
| 离双色 LED ≥50mm | LED 在 (-22,18)，距 91mm → 状态灯不会污染读数 |
| 线能顺线束走 | 到 ESP32 (-100,-50) 约 50mm，3 根线直接下落到面包板左区 |
| 不压其它件 | 底座 30×30 → x -125..-95 / y -20..10；面包板前缘 -27.2、花盆前缘 19、08 扎线座 x≥-90，都不碰 |

排除的候选：**前排中央 (-15,95)** 拍摄最好看但走线 170mm 要绕屏架；**直接插面包板** 零打印但板子立着、LDR 侧向朝前，照片没有成品感。

---

## 二、模型 11_ldr_stand

| 段 | 尺寸 | 说明 |
|---|---|---|
| 台锥底 | 24×24 → 30×30，高 4 | 14° 斜面 |
| 收腰柱 | 11→10，z 4~26 | 2° |
| 托盘 | 34×18×4.2，**45° 仰角** | 与屏架同语言；托底 45° = 自支撑，任意宽度都不塌 |
| 板槽 | 33.2×15.2 × 2.6 | 模块 32×14×1.6，单边 0.6 |
| 排针过线 | 上缘 **12×4.5 贯通槽** | 4P 塑壳 2.5 + 杜邦头 2.5 从托背穿出，落在托盘后上方空中 |
| 总高 | 33.85 | 实体 7.7 g |

**为什么不装平托盘**：平托盘在 10×10 柱上会有 12mm 平板悬空（和旧 07 一个毛病）；45° 托盘把整个底面变成斜裙，免支撑。

---

## 三、装配与走线

- 座：`(-110, -5, PT)`；模块：32×14×1.6 转 -45°，中心 `(-110, -4.79, PT+26.21)`（沿托盘法向 +0.3）
- 模块×座干涉：**0.00 mm³**（法向 -0.2 → 81 mm³、0 → 0，说明贴槽底正好）
- 新增 3 根跳线（VCC/GND/AO，DO 不接）：从托背上缘杜邦头下落到面包板左区，`check_wires` 总数 **22 → 25 根，穿模 0**

## 四、验证与代价

| 项 | 结果 |
|---|---|
| 几何 | watertight · **bodies=1** · 34×30×33.85 · z_min=0 · 7.7 g |
| `check_base_fit` | 光敏电阻座 z_min=8.0、干涉 0.0 → 全部通过 |
| `check_wires` | 25 根 / 0 穿模 |
| 切片 | **18m31s / 4.9 g / 1645 KB** |
| 十件合计 | **8h34m / 338.1 g**（原 9 件 8h15m / 333.2 g） |
| 切片警告 | `floating cantilever`：托盘下缘比柱前脸多 1.4mm 悬挑。试过把托盘下移 1.4 / 柱前移 2 消除，两种都会让托盘与柱**分离（bodies=2）** → 保留 1.4mm（45° 斜面上的小台阶，免支撑可打）。若实打塌边，把 `post_t` 10→12 重跑 |
