## 五、已知会踩的坑（先看，别重复试错）

| 现象 | 先查什么 | 出处 |
|---|---|---|
| WiFi 连不上、一直打点 | 热点是不是 5GHz；校园网是否要认证页 → 换手机 2.4G 热点 | 方案书 §六 风险表 |
| `[MQTT] 失败(rc=2)` | 巴法云要求 **clientID = UID**，`config.h` 里 UID 是否复制全（含首尾空格） | 固件 `mqttConnect()` |
| 连上了但面板没数 | 主题名对不对；巴法云控制台是否把该主题设成了"开关/插座"类型 | 11.1 |
| 发 `on` 没反应 | 服务端残留旧消息 → 固件收到后会**回写 `off`** 防重复触发；先看串口有没有 `[MQTT] 收到` | 固件 `mqttCallback()` |
| 面板数据忽有忽无 | 免费版连接数/消息数限额；热点断流 | 巴法云控制台 |
| 远程浇了但水泵不动 | 大概率不是上云问题：查 `EN_WATER` 是否 1、继电器极性、标定是否已回填 | `docs/操作手册/花房接线规划表.md` §六 |

> 真实踩坑**当场**补进这张表（现象 → 根因 → 处置 → 证据）；报告"失败与排查"章节直接取用，事后回忆写不真。
