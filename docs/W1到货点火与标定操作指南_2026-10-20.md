## 步骤 0：先确认电脑认得板子（30 秒）

**插线前先看这一步**，能省掉后面一堆无谓排查。

1. 用**自带的数据线**（不是充电线）把 ESP32 插电脑 USB 口。插反了不要硬怼，USB 口是梯形的，方向不对插不进去。
2. 跑这条命令看端口：

```bash
"C:/Users/junbo/AppData/Local/Temp/acli/arduino-cli.exe" board list
```

**看结果**：

| 输出 | 含义 | 下一步 |
|---|---|---|
| 出现 `COM5`（或别的 COM 号） | 驱动正常，继续步骤 1 | 记下这个 COM 号 |
| 出现 `COM5` 但后面写 `Unknown` / 一串 `?` | 驱动没装或没装对 | 走下面的「驱动修复」 |
| **空输出 / `No boards found`** | 板子没插、数据线是充电线、或驱动缺失 | 先换一根线试；还不行走「驱动修复」 |

**驱动修复**（Windows 11）：
- 插着板子，打开「设备管理器」，找「端口 (COM 和 LPT)」
- 看到 `USB-SERIAL CH340 (COMx)` 带**黄色感叹号** → 右键 →「卸载设备」→ 拔插板子 → Windows 自动装
- 整个「端口」分类里**根本没有 CH340** → 装驱动：搜索「CH341SER.EXE」（南京沁恒 / WCH 官网），或用 Arduino IDE 自带：`C:\Program Files (x86)\Arduino\drivers\arduino\CH341SER.EXE`（本机已装过 CH341SER.INF，版本可用）
- 装完**拔插一次板子**再跑 `board list`

> 本机已确认：`CH341SER.INF`（oem265.inf）已在系统里，驱动这一环基本是通的。所以**空输出最可能是数据线只供电不传数据**，先换线。

## 步骤 1：接线（只接土壤传感器，10 分钟）

> ⚠️ **焊接不是前置条件**（2026-10-20 更新）。实验室的电烙铁 / 焊锡丝 / 万用表目前**都没借到**，传感器是裸板三个空焊孔。
> 四条免焊路径与操作细节见 **`docs/W1无烙铁接线方案_2026-10-20.md`**。最省事的一条：杜邦线公头（0.64mm 方针）直接插进 PCB 的孔，母头插 ESP32 排针。
> 本步骤按"已接好线"来讲。

ESP32 侧看丝印，**只接三根线**：

| 传感器针脚 | → | ESP32 | 必看 |
|---|---|---|---|
| **VCC** | → | **3V3** | ⚠️ **必须 3.3V**，接 5V 会超出 ESP32 ADC 量程，可能烧板 |
| **GND** | → | GND | 任一 GND 即可 |
| **AOUT** | → | **GPIO34** | ⚠️ 只能接 34/35（ADC1 组）；接错脚读数永远是 0 |

**三处最容易踩的坑**：

1. **GPIO34 是"只进不出"脚**——没有内部上拉、不能输出，只能接传感器输出。
2. **别接 GPIO35**——那是光敏传感器的位置。两个都插也能跑，但光敏没接会读到乱跳的数，干扰你判断土壤读数。
3. **一定要共地**——传感器的 GND 必须和 ESP32 的 GND 连一起，不能只接 VCC 和 AOUT。

**拍照存档**：接好线拍一张接线照片，命名 `W1-3.1-接线.jpg`，放 `素材/`。报告要图。

## 步骤 3：看串口，确认板子活着

**方式 A —— 用 Arduino IDE**（最直观）：
1. 打开 Arduino IDE → 选板子 `ESP32 Dev Module` → 选端口 `COM5`
2. 工具 → 串口监视器 → 波特率 **115200**（这步最容易漏，115200 不是默认的 9600）
3. 复位板子，应该看到：

```
#SOILCALIB,1
#READY,soil_pin=34,interval_ms=100,avg_n=10
#CMD,R=reset,M=mark,P=ping
RAW,1523,3198
RAW,1624,3201
...
```

**看到 `RAW,` 开头的行 = 板子活着、接线通、ADC 在读。** 数值在 3000 上下 = 探针在空气中，正常（电容式传感器空气里读数偏高）。

**方式 B —— 用现成脚本**（会自动统计，不用自己看）：

```bash
cd "D:/Documents/workbuddydocument/2026-10-17-08-59-13/outputs/花房代码/tools"
"C:/Users/junbo/.workbuddy/binaries/python/envs/default/Scripts/python.exe" soil_calibrate.py --list-ports
```

看到端口列出来就说明脚本和板子沟通正常。

## 常见问题速查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `board list` 空 | 数据线只供电不传数据 | 换一根线（最常见） |
| `board list` 有端口但显示 Unknown | 驱动没装好 | 设备管理器卸载 CH340 → 拔插 → 重装 CH341SER.EXE |
| 串口没输出 / 乱码 | 波特率不是 115200 | 串口监视器改 115200 |
| `not responding / not in sync` | ESP32 没进下载模式 | 按住 BOOT，出现 Connecting 后松开 |
| 串口一直重连（每秒刷一次） | 波特率错位 | 同上，改 115200 |
| raw 恒为 0 | AOUT 没接到 GPIO34 / 没共地 | 重查接线，量一下 AOUT 对 GND 有没有电压 |
| raw 恒为 4095 | AOUT 悬空 / VCC 没接 / 接了 5V | 重查 VCC 是否在 3V3 |
| 干湿差 < 800 | 探针根部没全湿，或模块坏了 | 换一杯水重测；仍不行换传感器 |
| 湿度一直显示 0% | 干点填得比湿点小（填反了） | 脚本会自己拦；真发生了改 `SOIL_RAW_DRY` / `SOIL_RAW_WET` 顺序 |
