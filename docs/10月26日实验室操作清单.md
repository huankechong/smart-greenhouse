#### ⚠️ 泵的电源是什么（第 3 件的前置）

USB 泵要 **5V/1A 以上**的 USB 电源。三选一：

| 电源           | 说明                                                  |
| ------------ | --------------------------------------------------- |
| **充电宝**（推荐）  | 有输出口就行；**注意带输出口的，不是只有输入口**                          |
| USB 充电头 + 排插 | 实验室通常有排插                                            |
| **电脑 USB 口** | ⚠️ **不推荐** —— 泵启动瞬间电流可能让 USB 口过流保护断开，且继电器接线错误时有烧口风险 |

> 没带充电宝就用实验室排插 + USB 充电头。

#### ⚠️ 水的两个预案

文档里没写 8.2 的水从哪来，按现场情况二选一：

| 情况              | 做法                                |
| --------------- | --------------------------------- |
| 实验室**有水龙头/饮水机** | 用 1L 桶接半桶即可（约 500ml 够测 5 次 10 秒）  |
| **没有水源**        | 自带 **1 瓶 500ml–1.5L 矿泉水**（宿舍灌好带去） |

> 💡 8.2 用不了多少水：3W 泵浇 10 秒大约 200–300ml，**带 1L 绝对够**。

### 第 2 件：8.1 继电器接入（30 分钟）

**接线**（面包板）：

```
ESP32 GPIO26  →  继电器 IN
ESP32 3V3     →  继电器 VCC（多数模块 3.3V 可用；若模块标 5V 就接 5V/5V 脚）
ESP32 GND     →  继电器 GND
```

**烧测试固件**（不是主固件 —— 主固件没有手动触发入口；板子上现在已是这个固件，**可跳过烧录直接测**）：

```bash
arduino-cli upload -p <端口> --fqbn esp32:esp32:esp32 outputs/花房代码/RelayPumpTest
```

**串口 115200，发指令测**：

```
h          → 看帮助
on         → 继电器应"咔"一声吸合，模块 LED 亮
t          → 看状态（应显示"吸合(泵转)"）
off        → "咔"一声断开
w 3        → 3 秒后自动断开（提前验证定时功能）
```

**验收**：

- [ ] 串口打 `on/off` 时能听到继电器"咔哒"
- [ ] 继电器模块上的指示灯同步亮灭
- [ ] 串口状态打印正确（吸合/断开 + 累计时长）
- [ ] **拍照**（素材 W2-8.1）

> ⚠️ 如果 `on` 没反应但串口正常 → 先改 `RELAY_ACTIVE_HIGH` 为 0 重烧（极性反了）。

### 第 3 件：8.2 水泵联调（45 分钟）

**接线**（⚠️ 水路远离电路！桌面垫纸巾）

> 🔧 **原理**：继电器是个「电控开关」，**只串在水泵电源的正极回路上**；  
> 水泵另一根线直连电源负极、**不经过继电器**。  
> 不是"两根线各接一个脚"，而是**串在正极中间**。

**接线图**

```
     USB 5V 电源
      │        │
   正极(红)  负极(黑)
      │       │
  ┌───┴───┐    │
  │ 继电器 │   │
  │ COM NO│   │
  └─┬───┬─┘    │
    │   └──────┼──→ 水泵红线
    └──────────┼──→ （COM ← 电源正极）
              └──→ 水泵黑线（直连负极）
```

**3 步接法**

| 步     | 动作                                           |
| ----- | -------------------------------------------- |
| **1** | **USB 5V 正极** → 继电器 **COM**                  |
| **2** | 继电器 **NO** → **水泵红线**                        |
| **3** | **水泵黑线** → **USB 5V 负极（GND）** ← **直连，不过继电器** |

- 继电器吸合 → COM 与 NO 接通 → 正极通到水泵 → **泵转**
- 继电器断开 → COM/NO 断开 → 水泵断电 → **泵停**

**用 USB 延长线接（**&#x4E0D;剪水&#x6CF5;**）**

清单里有 **绿联 USB2.0 延长线 1m（A 公 - A 母，¥13.91 已到货）** —— 它是最省事的转接件：

> **核心思路：剪【延长线】，不剪【水泵】。**  
> 水泵原装线保持完整（保保修、不缩短）；延长线是消耗品，剪了就剪了。

**做法（4 步）**

| 步     | 动作                                                                   |
| ----- | -------------------------------------------------------------------- |
| **1** | **从中间剪断 USB 延长线**（不要剪两端插头），得两段：**A 公侧**（插电源那头）和 **A 母侧**（插水泵那头）      |
| **2** | 两段各剥出**红 / 黑**（**白、绿是数据线，不接** → 用绝缘胶带包住，防碰到红黑短路）                     |
| **3** | **A 公侧的红** → 继电器 **COM**；**继电器 NO** → **A 母侧的红**（裸线直接压进模块的螺丝端子）      |
| **4** | **A 公侧的黑 ↔ A 母侧的黑** 直连（用 **1 个 WAGO 221** 对接；没有 WAGO 就剪一段短铜线绞接 + 胶带） |

**接完的样子**

```
 [充电宝/5V适配器]
        │ USB-A 公
 ┌──────┴──────┐
 │ 延长线 A 公侧 │
 └──┬───────┬──┘
   红R1     黑B1
    │        │
 [继电器]     │
 COM   NO     │
  │     │     │
  │     └─────┼──→ 红R2 ─┐
  │           │          │
  └───────────┼──────────┘（R1 接 COM，NO 接 R2）
              │
           WAGO 对接 B1↔B2
              │
 ┌────────────┴─┐
 │ 延长线 A 母侧 │
 └──────┬───────┘
        │ USB-A 母
      [水泵 USB 公头]
```

**WAGO 只用到 1 个**（黑线对接）；两根红线直接压进继电器的 COM / NO 螺丝端子。

**为什么不用剪水泵线（这条路废弃）**

| 方案            | 后果                                            |
| ------------- | --------------------------------------------- |
| ~~剪水泵 USB 头~~ | 水泵线变短、失去保修、剪坏就没了（泵是贵的那件）                      |
| **剪延长线（推荐）**  | 泵无损；延长线 ¥13.91 剪了不心疼；两端还各带标准 USB 头，插电源/水泵都是即插 |

> 💡 剥线没专用钳就用剪刀**转圈划外皮**再拉掉，别一刀切到底（会切断铜丝）。剥 8–10mm 够。

**⚠️ 发 `on` 但继电器不吸合 —— 按这两条查**

| 现象                   | 原因                                     | 处理                                                     |
| -------------------- | -------------------------------------- | ------------------------------------------------------ |
| 串口打"吸合"，但模块没"咔哒"、灯不亮 | **模块 VCC 供电不足**：多数模块要 **5V**，接 3V3 带不动 | 模块 VCC 改接 ESP32 的 **5V / VIN 脚**（USB 供电时该脚有 5V）        |
| VCC 已 5V 仍不吸合        | **3.3V 逻辑触发不了 5V 模块**（高电平阈值不够）         | ① 把 `RELAY_ACTIVE_HIGH` 改 **0** 重烧试低电平触发 ② 换 3.3V 兼容模块 |

> 📌 模块 VCC 接 5V 时，**IN 仍接 GPIO26（3.3V）**，绝不能把 5V 灌进 GPIO。

**测试**：

1. 水泵进水口浸在 1L 桶（半桶水），出水口对着量杯/另一个容器
2. 串口发 `w 10` → 泵转 10 秒后自动停
3. 量出水量、记下来
4. 重复 3 次（10 秒 / 5 秒 / 3 秒），填下面记录表

**量出水量用什么**：没带量杯就问实验室借量筒/量杯；都没有就用 **1L 桶本身刻度**（1L=1000ml，一格 100ml，误差 ±50ml 够用）或矿泉水瓶（标签 550ml 处做记号）。

**记录表**（填完拍照留档）：

| 次数 | 吸合时长      | 出水量 (ml) | 折算 ml/s | 备注 |
| -- | --------- | -------- | ------- | -- |
| 1  | 10 s      |          |         |    |
| 2  | 5 s       |          |         |    |
| 3  | 3 s       |          |         |    |
| 4  | 10 s（重复验） |          |         |    |

**算一个关键数**：`ml/s` 的平均值 → 后面固件里 `WATER_MS = 3000` 就是靠它折算"浇 3 秒出多少水"，答辩要讲。

**验收**：

- [ ] 泵能起停，无异响
- [ ] 出水正常（不是滴）
- [ ] 停水后管路不滴漏
- [ ] **拍出水视频**（素材 W2-8.2）

### 第 4 件：6 项传感器逐个点亮（1.5–2 小时，**从没做过实机**）

> ⚠️ 这一步是 W1 的欠账（之前没杜邦线做不了）。**每一项都要单独验证**，不要一次全接。

| # | 传感器        | 怎么接                                   | 怎么验                                                           | 通过标准                                   |
| - | ---------- | ------------------------------------- | ------------------------------------------------------------- | -------------------------------------- |
| 1 | **DHT11**  | DATA→GPIO33，VCC→3V3，GND→GND           | **烧传感器版固件**（EN_DHT=1+EN_OLED=1，见下方「固件三连烧」）                    | 串口出现 `温度=xx.xC 气湿=xx%`，读数合理（室温 25–32℃） |
| 2 | **光敏电阻**   | AO→GPIO35，VCC→3V3，GND→GND             | 主固件默认就读                                                       | `光照raw=xxx`；**手遮住读数明显变小**              |
| 3 | **土壤传感器**  | AO→GPIO34，VCC→3V3，GND→GND             | 主固件默认就读                                                       | `土壤raw=xxxx`；**插土里 raw 变小、空气里 raw 变大** |
| 4 | **OLED**   | SDA→GPIO21，SCL→GPIO22，VCC→3V3，GND→GND | 传感器版固件（同上，**注意 I2C 地址可能是 0x3C/0x3C 两款，代码默认 0x3C**；不亮先查接线再查地址） | 屏幕显示 4 行中文（土壤/光照/温度/气湿）                |
| 5 | **双色 LED** | 红→GPIO25，绿→GPIO27（或按模块丝印）             | 主固件默认驱动                                                       | 土壤湿→**绿灯亮**；土壤干→**红灯亮**                |
| 6 | **继电器**    | 见第 2 件                                | 测试固件                                                          | 已验                                     |

**每项通过后：手机拍一张串口截图或屏幕照片**（实验报告素材，W1 系列要求 ≥8 张）。

> 💡 **土壤传感器要先焊排针**（如果借到烙铁）。焊接顺序 **GND→OUT→5V**，每点 2–3 秒，焊完用万用表通断档验：GND↔OUT 响、GND↔5V 响、**OUT↔5V 不响**（响就短路了）。

### 第 5 件：浮球开关极性（10 分钟，趁万用表在手）

1. 万用表打**蜂鸣档**（两表笔碰一下确认响）
2. 两表笔分别接浮球**两根引出线**
3. **竖直拿，杆尖朝下**（= 装进桶里的姿态，浮子滑到杆尖 = 模拟"没水"）→ 记「响/不响」
4. **倒过来，杆尖朝上**（浮子滑到另一端 = 模拟"有水"）→ 记「响/不响」

**判断**：

| 杆尖朝下（没水） | 杆尖朝上（有水） | 结论        | 参数                                       |
| -------- | -------- | --------- | ---------------------------------------- |
| 不响       | **响**    | 有水闭合（常开型） | `LEVEL_WET_CLOSED = true` ← **当前默认，不用改** |
| **响**    | 不响       | 没水闭合（常闭型） | 改成 `false`                               |
| 都响 / 都不响 |          | 开关坏了      | 换一个                                      |

> 浮子有时候要推到**端点**才动作，拿在手里不响就用手指把浮子硬推到杆的最顶端再试。

## 五、测试固件指令速查（抄在手边）

| 指令     | 作用                        |
| ------ | ------------------------- |
| `h`    | 显示帮助                      |
| `on`   | 继电器吸合（泵转）                 |
| `off`  | 继电器断开（泵停）                 |
| `w 10` | 吸合 10 秒后自动断开（**8.2 用这个**） |
| `auto` | 自动循环：吸合 3 秒 / 停 10 秒      |
| `stop` | 退出自动 + 断开                 |
| `t`    | 看当前状态与累计吸合时长              |
