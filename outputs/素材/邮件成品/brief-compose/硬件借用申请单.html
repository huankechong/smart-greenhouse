项目背景与目标：家庭及花店日常养护中，浇水时机与水量主要凭经验判断，外出时植株无人照管，缺水或浇水过量都会损伤植物。本项目旨在制作一套桌面级「智能花房养护站」，实现土壤干湿自动监测与按需浇水、环境数据云端记录，解决"何时浇、浇多少、出门没人管"的实际问题。项目为课程期末个人项目，最终交付物为实物 demo（现场演示自动浇水与手机查看）+ 实验报告 + 答辩汇报。

系统组成与工作原理：系统按「感知 → 决策 → 执行 → 上云」四层设计——① 感知层：电容式土壤湿度传感器插入花盆实时监测干湿，温湿度传感器与光敏电阻采集环境温湿度、光照数据；② 决策层：自购 ESP32 主控对读数做阈值判断（如土壤湿度低于设定值即判定缺水）；③ 执行层：主控驱动继电器接通微型水泵自动浇水，双色 LED 同步指示状态（绿色 = 正常 / 红色 = 缺水报警）；④ 云端层：通过 WiFi 将数据上传免费物联网平台（巴法云），手机微信小程序可查看实时数据与历史曲线、并远程手动浇水。整体工作闭环：传感器发现土壤变干 → 主控判断 → 水泵自动补水 → 数据同步到手机。

关键技术细节：土壤湿度采用电容式检测原理（土壤含水量改变介电常数，转化为电信号读数），相比裸露金属探针的电阻式方案，探针不带土内电流、不电解腐蚀，长期浸泡读数稳定，对植株无害。三路传感器分别通过 ADC（模数转换）与数字接口接入主控；OLED 显示屏走 I2C 总线，仅占用两个引脚；继电器实现控制电路（5V 弱电）与水泵回路（USB 供电）的物理隔离，浇水电通路与电子元件分置于外壳两侧，杜绝漏水导致短路的风险。软件层面采用多次采样取平均的滤波方法抑制读数抖动，并以"浇一段—停—复测"的间歇策略防止一次浇过头，浇水后延时复核确认湿度回升才结束本次浇水动作。
