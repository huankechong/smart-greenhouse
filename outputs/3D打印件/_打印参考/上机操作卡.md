## 四、可能出问题的地方（按概率排）

| 现象 | 原因 | 处理 |
|---|---|---|
| **底盘四角翘边** | brim 不够 / 板不干净 / 冷却太快 | 重打该片，brim 加到 10mm，板用温水+洗洁精洗一遍擦干 |
| **首层不粘** | 板脏 / 调平偏 / 首层太快 | 别硬打，重跑自动调平 + 洗板 |
| **10 水箱盖裙边塌** | 裙边高、壁薄 | 若塌，降到 0.16 层高重切 |
| **06c 螺纹滑丝** | 流量偏大 / 孔径偏大 | 别打底盘，先排查流量标定 |
| **04 托盘上缘缺口处毛边** | 13mm 宽缺口是悬空边 | 正常现象，砂纸轻磨即可 |
| **11 托盘下缘有 1.4mm 小台阶** | 切片器报 floating cantilever | 免支撑可打，塌了再改 `post_t` 12 重跑 |
| **中途断料** | 卷上不足 | 记层号，用剩余料补打 |
