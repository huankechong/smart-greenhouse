## 五、⚠️ 上机前检查

1. **耗材**：1kg PLA 一卷够（用 325g），但**建议确认卷上余量 ≥ 400g**（含 purge 与失败重试）
2. **打印板**：X2D 支持纹理 PEI / 光面 PEI 等；PLA 用纹理 PEI 附着力好、好脱模
3. **底盘必开 brim 8mm**（160×230 大平面 + 20% 填充，边角易翘）
4. **免支撑**：9 件全部已按"免支撑"几何设计（顶面朝下贴床 / 全垂直壁），切片预设未启用支撑
5. **层高 0.2 / 3 墙 / 20% gyroid** 已固化在 gcode 里，上机直接选文件即可

## 六、复现命令与踩坑

```bash
# 已封装在 .workbuddy/batch_slice.py，核心调用：
bambu-studio.exe --export-3mf <名>.3mf --slice 1 --outputdir <输出目录> \
  --load-settings "…\machine\Bambu Lab X2D 0.4 nozzle.json;…\process\0.20mm Standard @BBL X2D.json" \
  --load-filaments "…\filament\Bambu PLA Basic @BBL X2D 0.4 nozzle.json" \
  --wall-loops 3 --brim-type outer_only --brim-width <3|5|8> \
  <输入.stl>
```

> 📌 **踩坑记录（值得记）**：`--export-3mf` 后面**必须跟输出文件名**（不是布尔开关）。
> 写成裸开关会报 `"The input files to the slicer are not found."` 且 exit=-3 ——
> 这个错误信息**完全不指向真实原因**，我为此排查了 20 分钟（还试了中文路径、代理变量、PowerShell/CMD 各种调用方式）。
