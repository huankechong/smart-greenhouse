## 二、上机顺序（**这个顺序有讲究，别打乱**）

### ① 第一件永远是 06c 连接块（7 分钟）

**为什么**：它是全项目最简单、最便宜的一件。用它验证「机器正常 / 参数对 / 附着力够 / 料没断」，**失败了只损失 3 克料**。

打完立刻做验收：
- 用 **M3×6 自攻螺丝**试拧一下 φ2.8 引导孔 → **手感要有阻力但不能裂**
- 太松（滑丝）→ 说明孔偏大或流量不足，**先别打底盘**
- 太紧/裂开 → 说明过挤，同样先排查

### ② 然后是底盘两片（大头）

| 顺序 | 文件 | 时长 | brim |
|---|---|---|---|
| 1 | `06a_base_left/06a_base_left.gcode` | 2h27m | **8mm 必开** |
| 2 | `06b_base_right/06b_base_right.gcode` | 2h33m | **8mm 必开** |

**注意**：
- 底盘是 160×230 大平面，**必须确认 brim 开了 8mm**（已在 gcode 里，但选文件后瞄一眼预览）
- 打完**别急着撕 brim**，等托盘冷却到 40℃ 以下再取（热撕会翘边）
- 两片打完先**对拼一次**（插 φ4×16 定位销 + 06c 连接块），确认拼缝齐平

### ③ 最后打小件

| 文件 | 时长 | brim |
|---|---|---|
| `10_tank_lid` 水箱盖 | 1h02m | 5mm（顶面朝下印） |
| `01b_sensor_holder` 传感器支架 | 35m | 5mm |
| `07_dht11_holder` DHT11 座 | 34m | 3mm |
| `03_tube_clip` 管夹 | 17m | 3mm |
| `04_oled_stand` OLED 支架 | 17m | 3mm |
| `08_cable_clip` 扎线座 | 9m | 3mm |

## 三、每批开工前的 30 秒检查

- [ ] **打印板干净**（无上次残留、无指纹油）—— PLA 用**纹理 PEI 板**附着力最好
- [ ] **耗材够**：本批需求见下表；**卷上余量建议留 ≥1.2 倍**
- [ ] **料盘转动顺畅**（无卡料、无打结）
- [ ] **喷嘴无残料**（有的话用镊子清，别用手）
- [ ] **选文件后看预览**：确认 brim 在、支撑没被误开、件位置没超床

| 批次 | 耗材需求 |
|---|---|
| 06a | 119 g |
| 06b | 124 g |
| 小件七件合计 | 82 g（10:44.6 / 01b:10.1 / 07:8.9 / 04:9.1 / 03:3.3 / 08:3.1 / 06c:2.9） |
| **总计** | **325 g** |

## 四、可能出问题的地方（按概率排）

| 现象 | 原因 | 处理 |
|---|---|---|
| **底盘四角翘边** | brim 不够 / 板不干净 / 冷却太快 | 重打该片，brim 加到 10mm，板用温水+洗洁精洗一遍擦干 |
| **首层不粘** | 板脏 / 调平偏 / 首层速度太快 | 别硬打，先重跑一遍自动调平 + 洗板 |
| **10 水箱盖裙边塌** | 裙边 7mm 高、壁 2.8 偏薄 | 该件已按 0.2 层高切，若塌可降到 0.16 层高重切 |
| **06c 螺纹滑丝** | 流量偏大 / 孔径偏大 | 别打底盘，先排查流量标定 |
| **中途断料** | 卷上不足 | 记下断在第几层，用剩余料补打 |

## 五、打完的验收清单

- [ ] 9 件齐全（02 泵座**本来就不打**，别找）
- [ ] 06a + 06b 能拼上，拼缝齐平，φ4×16 定位销能插进

- [ ] 03 管夹的 C 形孔能压进 φ10 硅胶管（压进去不会自己掉）
- [ ] 04/07/08 就位无误
