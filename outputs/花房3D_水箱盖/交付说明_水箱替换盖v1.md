## 一、这件是什么

水箱从"118×90 方盒（原 v1 装配占位）"改为**市售 1L PP 打包桶**（淘宝官方标注尺寸，
¥1.55/个 ×5 + 运费）。浮球开关 **P52**（M10 螺纹 / 常开 / 0~110V，¥7.43 ×2）要垂直
装在桶顶，原装盖没有孔——本件**替换原装盖**，桶本体不打孔（商品无损、可逆）。

| 桶尺寸（官方标注图，**到货复测**） | 值 |
|---|---|
| 上径（口外径） | 136 |
| 口内径 | 120 |

## 二、结构（打印朝向 = 盖顶面朝下贴床，凸台/裙边朝上）

| 特征 | 尺寸 | 作用 |
|---|---|---|
| 盖板圆盘 | φ142.4 × **4 厚** | 主板。板厚定 4 是给 M10 螺母留咬合（螺纹长 6，板 4 + 凸台 0.8 → 螺母在桶内侧拧入 4.8mm，够锁紧） |
| 螺母凸台 | φ20 × 0.8 环形，盖板下面（桶内侧） | **替代垫片**（2026-10-19 定版免垫片方案）：M10 六角螺母对角 19.6 < 20，整个坐在凸台环面上承力 |
| 中心孔 | φ10.5 贯穿 | P52 浮球开关杆（M10 + 0.5） |
| 水管孔 | φ10 @ 距中心 22（泵侧 −Y） | 硅胶管 φ8 穿盖入桶接泵 |
| 过线孔 | φ8 @ 距中心 30（+Y） | 水泵 USB 线穿盖出桶 |
| 裙边 | 内 φ136.8 × 高 8，壁 2.8 | 套住桶口外壁（径向隙 0.8），盖不侧滑 |
| 指位缺口 | 2 × φ26 半圆（±X 板缘） | 开盖抠手 |

打印参数建议：PLA，0.2mm 层高，壁 3 圈，顶底 4 层，**首层整圆无支撑**（唯一悬空是
凸台/裙边朝上竖印，天然免撑）。约 51g。

## 三、几何校验（`check_geometry()` 参数反算，非目测）

| 检查项 | 数值 | 判定 |
|---|---|---|
| 螺母对角 19.6 < 凸台 φ20 | 0.4 余量 | ✓ |
| 水管孔缘 ↔ 凸台 | 11.75 | ✓ |
| 过线孔缘 ↔ 凸台 | 20.75 | ✓ |
| 两孔最远缘 ↔ 裙边内壁 | 41.4 / 34.4 | ✓ |
| **浮球杆尖 ↔ 泵顶垂直间隙** | **134.5**（泵在桶内 −Y 12，与浮球环 XY 不重叠） | ✓ |
| watertight / 单体 / z_min=0 | — | ✓（check_report.json） |

浮球安装后杆尖（使用态）= 槽底 3 + 桶身 120 + 板 4 + 有效长 52 → 距桶内底 179；
泵顶 = 3 + 桶底 1.5 + 座 3 + 泵 30 + 嘴 7 = 44.5。**杆尖远在泵上方**，浮球环下沿
(z≈151) 也高于泵顶 106mm，全程不干涉。

## 四、报警点容量账（P52 为什么是 52）

- 桶内水深 = 满水 1200ml 对应约 101mm（1L 刻度线附近）。
- P52 触发点 = 杆尖下 52mm ≈ 水深 52mm → **报警时桶内剩约 700ml**。
- 单轮浇水上限 = 6 轮 × 3s × ~36ml/s ≈ 650ml < 700ml → **一次满水周期内不会中途断水**。
- 对比 P43（有效长 43，报警点 67mm，剩 578ml）< 650ml，不够——这是 2026-10-19
  从 P43 改单 P52 的依据。

## 五、到货后要做的三件事

1. **复测桶口**：卡尺量口外径 / 口内径 / 桶身高，若与 136/120/120 偏差 >0.5，
   改 `P10` 顶部参数重跑脚本（30 秒出新 STL）。
2. **复测浮球**：万用表蜂鸣档按《花房接线规划表》第 8 节验收三步确认常开极性。
3. **试装**：盖扣桶口（0.8 径向隙应手压到位不晃）、浮球穿中心孔上螺母、水管/USB 线
   过孔——都是免胶免工具装配。
