# 智能花房养护站 · Smart GreenHouse（BiUH IPW Final Project）

ESP32 + 土壤湿度/光敏/DHT11 传感 → 自动浇水（继电器 + 底吸泵）→ 双色 LED 状态灯 → OLED 显示 → 巴法云 MQTT 上云 + 微信小程序远程浇水。

**这个仓库里有两样东西**：一套能烧的 Arduino 固件，和一套**能直接上机打印的 9 个结构件**（外加整机示意模型）。

## 四、把件打出来（三步）

1. **先打 `06c_joint_block`**（10 分钟）——用 M3 自攻试拧一下 φ2.8 引导孔，确认咬合手感，再上大件。
2. 把 `STL/*.stl` 拖进 Bambu Studio：0.2 层高 / 20% gyroid / 3 墙 / **免支撑** / 底盘开 brim 5–8mm。
3. 五金只要三样：**M3×6 盘头自攻 ×8**、**φ4×16 定位销 ×2**、PH1 螺丝刀。⚠️ M3×8 会穿出底面 1.8mm。

装配顺序（定位销必须**先**插、再放连接块）见 `outputs/花房3D_整机底盘/交付说明_整机底盘两片式v1.md` 第三节。

## 五、改了参数怎么重出全套

```bash
PY="C:/Users/junbo/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
cd outputs

$PY 花房3D_P0/p0b_sensor_hook.py        # 01b 盆沿挂钩
$PY 花房3D_P0/p0_models.py              # 02 / 03
$PY 花房3D_P1P2/p1p2_models.py          # 04 / 07 / 08
$PY 花房3D_整机底盘/base_2pc_models.py   # 06a / 06b / 06c
$PY 花房3D_整机装配/build_assembly.py    # 整机 glb + 四视图
$PY 花房3D_整机装配/build_html.py        # 单文件离线 HTML
```

改哪个尺寸就改对应脚本顶部的 `PARAMS` / `P` 常量，**不要手改 STL**。

### 改完必须跑校验

| 脚本 | 查什么 |
|---|---|
| `花房3D_整机装配/check_base_fit.py` | 每个件是否坐进该坐的槽、件×底板干涉、空槽/缺槽 |
| `花房3D_整机装配/audit.py` | 11 个 STL 几何自检 + 两两干涉 + 文档数字对账 |
| `花房3D_整机装配/check_occlusion.py` | OLED 屏被谁挡（射线采样） |
| `花房3D_整机装配/verify_html.js` | 无头 Chromium 实开 HTML，查 WebGL / JS 报错 |
