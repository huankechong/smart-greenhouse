# 智能花房养护站 · Smart GreenHouse（BiUH IPW Final Project）

ESP32 + 土壤湿度/光敏/DHT11 传感 → 自动浇水（继电器 + 底吸泵）→ 双色 LED 状态灯 → OLED 显示 → 巴法云 MQTT 上云 + 微信小程序远程浇水。

**仓库里有两样东西**：一套可烧录的 Arduino 固件，和一套可打印的 **10 个生产 STL**（06c 连接块实物 ×2，另有整机展示场景）。

## 四、重建结构件

```bash
PY="C:/Users/junbo/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
cd outputs/3D打印件

$PY 花房3D_P0/p0b_sensor_hook.py        # 01b
$PY 花房3D_P0/p0_models.py              # 03（02 作废但脚本保留）
$PY 花房3D_P1P2/p1p2_models.py          # 04 / 07 / 11
$PY 花房3D_追加件/p12_led_plug.py       # 12
$PY 花房3D_整机底盘/base_2pc_models.py   # 06a / 06b / 06c
$PY 花房3D_水箱盖/p10_tank_lid.py       # 10
```

改尺寸只改脚本顶部 `PARAMS` / `P`，禁止手改 STL。改完至少跑：

```bash
$PY 花房3D_整机装配/check_base_fit.py
$PY 花房3D_整机装配/check_wires.py
$PY 花房3D_整机装配/audit.py
```

`check_clearance.py` 可用于配合间隙快查；旧 `build_html.py` 展示管线已退役，不再作为交付链步骤。
