# 智能花房养护站 · Smart GreenHouse（BiUH IPW Final Project）

ESP32 + 土壤湿度/光敏/DHT11 传感 → 自动浇水（继电器 + 底吸泵）→ 双色 LED 状态灯 → OLED 显示 → 巴法云 MQTT 上云 + 微信小程序远程浇水。

**这个仓库里有两样东西**：一套能烧的 Arduino 固件，和一套**能直接上机打印的 10 个结构件**（外加整机示意模型）。

## 四、把件打出来（三步）

1. **先打 `06c_joint_block`**（10 分钟）——用 M3 自攻试拧一下 φ2.8 引导孔，确认咬合手感，再上大件。
2. 把 `STL/*.stl` 拖进 Bambu Studio：0.2 层高 / 20% gyroid / 3 墙 / **免支撑** / 底盘开 brim 5–8mm。
3. 五金只要三样：**M3×6 盘头（圆柱头）自攻 ×8**、**φ4×16 定位销 ×2**、PH1 螺丝刀。
   - ⚠️ **必须是自攻（牙尖、牙距宽），不能是机螺丝**——底板是 φ2.8 × 5.25 深**盲孔**，没螺纹也没法上螺母，机螺丝拧不进会撑裂 PLA。
   - ⚠️ **必须是盘头（圆柱头）**，配 φ6.2 × 1.8 深的圆柱沉孔；90° 锥形沉头坐不实。
   - ⚠️ M3×8 会穿出底面 1.8mm 刮桌面，只能用 M3×6。

装配顺序（定位销必须**先**插、再放连接块）见 `outputs/3D打印件/花房3D_整机底盘/交付说明_整机底盘两片式v1.md` 第三节。
